# Ultimo educational framework v0.2

134 defined course syllabuses, 536 lesson-level competencies, plus the original INT.learning competency (537 total). Ten courses have draft content; 124 have blueprints only. Content status remains independent of framework coverage. See [programme](../pathways/five-year.md), [assessment policy](assessment-policy.md), [lesson standard](lesson-standard.md), and [faculty index](faculty-index.md).

The framework is complete in coverage of the current catalogue, not a claim of exhaustive human capability or external accreditation.
