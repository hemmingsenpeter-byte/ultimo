# INT-105 — Cognitive biases

Framework defined; lesson content: **draft**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours.

## Lesson blueprints

### L01 — Confirmation bias

- **Outcome:** Explain confirmation bias in the context of cognitive biases.
- **Example brief:** Use a realistic fictional case involving confirmation bias; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to bias audit.
- **Knowledge check:** Explain confirmation bias from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of confirmation bias; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-105.L01`

### L02 — Anchoring and availability

- **Outcome:** Compare and distinguish anchoring and availability in the context of cognitive biases.
- **Example brief:** Use a realistic fictional case involving anchoring and availability; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to bias audit.
- **Knowledge check:** Explain anchoring and availability from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of anchoring and availability; correct application to a new case; clear rationale and limits.
