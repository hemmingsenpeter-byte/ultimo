# BUS-104 — Digital literacy

Framework defined; lesson content: **planned**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
None; prior learning may be demonstrated.

## Lesson blueprints

### L01 — Files networks and data

- **Outcome:** Explain files networks and data in the context of digital literacy.
- **Example brief:** Use a realistic fictional case involving files networks and data; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to workflow documentation.
- **Knowledge check:** Explain files networks and data from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of files networks and data; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-104.L01`

### L02 — Digital tools

- **Outcome:** Compare and distinguish digital tools in the context of digital literacy.
- **Example brief:** Use a realistic fictional case involving digital tools; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to workflow documentation.
- **Knowledge check:** Explain digital tools from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of digital tools; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-104.L02`

### L03 — Access and privacy

- **Outcome:** Apply access and privacy in the context of digital literacy.
- **Example brief:** Use a realistic fictional case involving access and privacy; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to workflow documentation.
- **Knowledge check:** Explain access and privacy from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of access and privacy; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-104.L03`

### L04 — Reproducible workflow

- **Outcome:** Evaluate and justify decisions about reproducible workflow in the context of digital literacy.
- **Example brief:** Use a realistic fictional case involving reproducible workflow; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to workflow documentation.
- **Knowledge check:** Explain reproducible workflow from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of reproducible workflow; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-104.L04`

**Artifact:** Workflow documentation.

All mapped criteria at level 2; no averaging away missing criteria. Level 3 requires independent novel application, delayed reassessment and appropriate review. Equivalent accessible written, oral, visual, simulated or supervised evidence; no personal disclosure required.

**Review:** Practitioner with relevant business, technology or privacy expertise.. Respect consent, privacy and applicable rules; source and subject review before publication.
