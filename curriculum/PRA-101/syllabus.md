# PRA-101 — Cooking

Framework defined; lesson content: **planned**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
None; prior learning may be demonstrated.

## Lesson blueprints

### L01 — Food hygiene and allergens

- **Outcome:** Explain food hygiene and allergens in the context of cooking.
- **Example brief:** Use a realistic fictional case involving food hygiene and allergens; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to safe meal plan.
- **Knowledge check:** Explain food hygiene and allergens from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of food hygiene and allergens; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-101.L01`

### L02 — Cooking methods

- **Outcome:** Compare and distinguish cooking methods in the context of cooking.
- **Example brief:** Use a realistic fictional case involving cooking methods; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to safe meal plan.
- **Knowledge check:** Explain cooking methods from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of cooking methods; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-101.L02`

### L03 — Timing and ingredients

- **Outcome:** Apply timing and ingredients in the context of cooking.
- **Example brief:** Use a realistic fictional case involving timing and ingredients; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to safe meal plan.
- **Knowledge check:** Explain timing and ingredients from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of timing and ingredients; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-101.L03`

### L04 — Waste reduction

- **Outcome:** Evaluate and justify decisions about waste reduction in the context of cooking.
- **Example brief:** Use a realistic fictional case involving waste reduction; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to safe meal plan.
- **Knowledge check:** Explain waste reduction from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of waste reduction; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-101.L04`
