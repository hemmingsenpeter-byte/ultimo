# CIV-105 — Governance

Framework defined; lesson content: **planned**. Year 4; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [CIV-103 — Law and rights](../CIV-103/syllabus.md)

## Lesson blueprints

### L01 — Institutional arrangements

- **Outcome:** Explain institutional arrangements in the context of governance.
- **Example brief:** Use a realistic fictional case involving institutional arrangements; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to institutional reform memo.
- **Knowledge check:** Explain institutional arrangements from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of institutional arrangements; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-105.L01`

### L02 — Public authority

- **Outcome:** Compare and distinguish public authority in the context of governance.
- **Example brief:** Use a realistic fictional case involving public authority; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to institutional reform memo.
- **Knowledge check:** Explain public authority from memory and apply it to a different example; state one limitation.

- **Competency ID:** `CIV-105.L02`

### L03 — Policy implementation

- **Outcome:** Apply policy implementation in the context of governance.
- **Example brief:** Use a realistic fictional case involving policy implementation; show reasoning, a contrasting case and limitations.

### L04 — Civic participation

- **Outcome:** Evaluate and justify decisions about civic participation in the context of governance.

- **Evidence:** Accurate explanation of civic participation; correct application to a new case; clear rationale and limits.
