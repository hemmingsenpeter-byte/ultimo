# MEN-103 — Motivation and procrastination

Framework defined; lesson content: **draft**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours.

## Lesson blueprints

### L01 — Avoidance

- **Outcome:** Explain avoidance in the context of motivation and procrastination.
- **Example brief:** Use a realistic fictional case involving avoidance; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to procrastination experiment.
- **Knowledge check:** Explain avoidance from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of avoidance; correct application to a new case; clear rationale and limits.
- **Competency ID:** `MEN-103.L01`

### L02 — Task decomposition

- **Outcome:** Compare and distinguish task decomposition in the context of motivation and procrastination.
- **Example brief:** Use a realistic fictional case involving task decomposition; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to procrastination experiment.

- **Evidence:** Accurate explanation of task decomposition; correct application to a new case; clear rationale and limits.
- **Competency ID:** `MEN-103.L02`

### L03 — If-then plans

- **Outcome:** Apply if-then plans in the context of motivation and procrastination.
