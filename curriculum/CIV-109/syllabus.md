## Lesson blueprints

### L01 — Demographic technological ecological drivers

- **Outcome:** Explain demographic technological ecological drivers in the context of civilisational futures.
- **Example brief:** Use a realistic fictional case involving demographic technological ecological drivers; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to country futures memo.
- **Knowledge check:** Explain demographic technological ecological drivers from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of demographic technological ecological drivers; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-109.L01`

### L02 — Alternative scenarios

- **Outcome:** Compare and distinguish alternative scenarios in the context of civilisational futures.
- **Example brief:** Use a realistic fictional case involving alternative scenarios; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to country futures memo.
- **Knowledge check:** Explain alternative scenarios from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of alternative scenarios; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-109.L02`

### L03 — Distributional trade-offs

- **Outcome:** Apply distributional trade-offs in the context of civilisational futures.
- **Example brief:** Use a realistic fictional case involving distributional trade-offs; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to country futures memo.
- **Knowledge check:** Explain distributional trade-offs from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of distributional trade-offs; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-109.L03`

### L04 — Robust strategy

- **Outcome:** Evaluate and justify decisions about robust strategy in the context of civilisational futures.
- **Example brief:** Use a realistic fictional case involving robust strategy; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to country futures memo.
- **Knowledge check:** Explain robust strategy from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of robust strategy; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-109.L04`
