# PRA-106 — Navigation and outdoor skills

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
None; prior learning may be demonstrated.

## Lesson blueprints

### L01 — Maps and scale

- **Outcome:** Explain maps and scale in the context of navigation and outdoor skills.
- **Example brief:** Use a realistic fictional case involving maps and scale; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to dry-land route plan.
- **Knowledge check:** Explain maps and scale from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of maps and scale; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-106.L01`

### L02 — Weather and terrain

- **Outcome:** Compare and distinguish weather and terrain in the context of navigation and outdoor skills.
- **Example brief:** Use a realistic fictional case involving weather and terrain; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to dry-land route plan.
- **Knowledge check:** Explain weather and terrain from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of weather and terrain; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-106.L02`

### L03 — Communication and turnaround

- **Outcome:** Apply communication and turnaround in the context of navigation and outdoor skills.
- **Example brief:** Use a realistic fictional case involving communication and turnaround; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to dry-land route plan.
- **Knowledge check:** Explain communication and turnaround from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of communication and turnaround; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-106.L03`

### L04 — Local advice

- **Outcome:** Evaluate and justify decisions about local advice in the context of navigation and outdoor skills.
- **Example brief:** Use a realistic fictional case involving local advice; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to dry-land route plan.
- **Knowledge check:** Explain local advice from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of local advice; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-106.L04`

## Assessment
**Artifact:** Dry-land route plan.

All mapped criteria at level 2; no averaging away missing criteria. Level 3 requires independent novel application, delayed reassessment and appropriate review. Equivalent accessible written, oral, visual, simulated or supervised evidence; no personal disclosure required.

**Review:** qualified practical safety reviewer. Draft educational framework only. Use fictional cases; no personal diagnosis, prescription, hazardous practice, financial/legal instruction or unqualified certification. Obtain qualified/local review before publication.
