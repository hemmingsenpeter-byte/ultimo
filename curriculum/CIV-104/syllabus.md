# CIV-104 — Geography and geopolitics

Framework defined; lesson content: **planned**. Year 4; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [CIV-101 — World history](../CIV-101/syllabus.md)

## Lesson blueprints

### L01 — Maps and resources

- **Outcome:** Explain maps and resources in the context of geography and geopolitics.
- **Example brief:** Use a realistic fictional case involving maps and resources; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to geopolitical briefing.
- **Knowledge check:** Explain maps and resources from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of maps and resources; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-104.L01`

### L02 — State interests

- **Outcome:** Compare and distinguish state interests in the context of geography and geopolitics.
- **Example brief:** Use a realistic fictional case involving state interests; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to geopolitical briefing.
- **Knowledge check:** Explain state interests from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of state interests; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-104.L02`

### L03 — Geopolitical explanations

- **Outcome:** Apply geopolitical explanations in the context of geography and geopolitics.
- **Example brief:** Use a realistic fictional case involving geopolitical explanations; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to geopolitical briefing.
- **Knowledge check:** Explain geopolitical explanations from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of geopolitical explanations; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-104.L03`

### L04 — Nonviolent policy options

- **Outcome:** Evaluate and justify decisions about nonviolent policy options in the context of geography and geopolitics.
- **Example brief:** Use a realistic fictional case involving nonviolent policy options; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to geopolitical briefing.
- **Knowledge check:** Explain nonviolent policy options from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of nonviolent policy options; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-104.L04`
