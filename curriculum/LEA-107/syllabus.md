## Lesson blueprints

### L01 — Diagnosis

- **Outcome:** Explain diagnosis in the context of strategy and execution.
- **Example brief:** Use a realistic fictional case involving diagnosis; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to strategy brief.
- **Knowledge check:** Explain diagnosis from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of diagnosis; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-107.L01`

### L02 — Strategic alternatives

- **Outcome:** Compare and distinguish strategic alternatives in the context of strategy and execution.
- **Example brief:** Use a realistic fictional case involving strategic alternatives; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to strategy brief.
- **Knowledge check:** Explain strategic alternatives from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of strategic alternatives; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-107.L02`

### L03 — Execution measures

- **Outcome:** Apply execution measures in the context of strategy and execution.
- **Example brief:** Use a realistic fictional case involving execution measures; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to strategy brief.
- **Knowledge check:** Explain execution measures from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of execution measures; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-107.L03`

### L04 — Adaptation

- **Outcome:** Evaluate and justify decisions about adaptation in the context of strategy and execution.
- **Example brief:** Use a realistic fictional case involving adaptation; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to strategy brief.
- **Knowledge check:** Explain adaptation from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of adaptation; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-107.L04`
