# COM-103 — Listening and questioning

Framework defined; lesson content: **planned**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
None; prior learning may be demonstrated.

## Lesson blueprints

### L01 — Reflective listening

- **Outcome:** Explain reflective listening in the context of listening and questioning.
- **Example brief:** Use a realistic fictional case involving reflective listening; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to listening simulation.
- **Knowledge check:** Explain reflective listening from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of reflective listening; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-103.L01`

### L02 — Question types

- **Outcome:** Compare and distinguish question types in the context of listening and questioning.
- **Example brief:** Use a realistic fictional case involving question types; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to listening simulation.
- **Knowledge check:** Explain question types from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of question types; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-103.L02`

### L03 — Fair summary

- **Outcome:** Apply fair summary in the context of listening and questioning.
- **Example brief:** Use a realistic fictional case involving fair summary; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to listening simulation.
- **Knowledge check:** Explain fair summary from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of fair summary; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-103.L03`

### L04 — Consent-based questioning

- **Outcome:** Evaluate and justify decisions about consent-based questioning in the context of listening and questioning.
- **Example brief:** Use a realistic fictional case involving consent-based questioning; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to listening simulation.
- **Knowledge check:** Explain consent-based questioning from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of consent-based questioning; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-103.L04`
