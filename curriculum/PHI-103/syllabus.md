# PHI-103 — Eastern philosophy

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [INT-102 — Logic and argument](../INT-102/syllabus.md)

## Lesson blueprints

### L01 — Confucian thought

- **Outcome:** Explain confucian thought in the context of eastern philosophy.
- **Example brief:** Use a realistic fictional case involving confucian thought; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to comparative text analysis.
- **Knowledge check:** Explain confucian thought from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of confucian thought; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHI-103.L01`

### L02 — Daoist thought

- **Outcome:** Compare and distinguish daoist thought in the context of eastern philosophy.
- **Example brief:** Use a realistic fictional case involving daoist thought; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to comparative text analysis.
- **Knowledge check:** Explain daoist thought from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of daoist thought; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHI-103.L02`

### L03 — Buddhist traditions

- **Outcome:** Apply buddhist traditions in the context of eastern philosophy.
- **Example brief:** Use a realistic fictional case involving buddhist traditions; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to comparative text analysis.
- **Knowledge check:** Explain buddhist traditions from memory and apply it to a different example; state one limitation.

- **Competency ID:** `PHI-103.L03`

### L04 — Comparative interpretation

- **Outcome:** Evaluate and justify decisions about comparative interpretation in the context of eastern philosophy.
- **Example brief:** Use a realistic fictional case involving comparative interpretation; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to comparative text analysis.
- **Knowledge check:** Explain comparative interpretation from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of comparative interpretation; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHI-103.L04`

## Assessment
**Artifact:** Comparative text analysis.

All mapped criteria at level 2; no averaging away missing criteria. Level 3 requires independent novel application, delayed reassessment and appropriate review. Equivalent accessible written, oral, visual, simulated or supervised evidence; no personal disclosure required.

**Review:** Philosopher or scholar of relevant tradition; avoid treating one tradition as universal.. Respect consent, privacy and applicable rules; source and subject review before publication.
