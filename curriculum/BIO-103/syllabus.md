# BIO-103 — Sleep

Framework defined; lesson content: **planned**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [BIO-101 — Human biology](../BIO-101/syllabus.md)

## Lesson blueprints

### L01 — Sleep stages

- **Outcome:** Explain sleep stages in the context of sleep.
- **Example brief:** Use a realistic fictional case involving sleep stages; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to sleep case analysis.
- **Knowledge check:** Explain sleep stages from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of sleep stages; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-103.L01`

### L02 — Circadian rhythms

- **Outcome:** Compare and distinguish circadian rhythms in the context of sleep.
- **Example brief:** Use a realistic fictional case involving circadian rhythms; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to sleep case analysis.
- **Knowledge check:** Explain circadian rhythms from memory and apply it to a different example; state one limitation.

- **Competency ID:** `BIO-103.L02`

### L03 — Sleep environment

- **Outcome:** Apply sleep environment in the context of sleep.
