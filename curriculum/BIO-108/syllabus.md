# BIO-108 — Ageing and preventive care

Framework defined; lesson content: **planned**. Year 5; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [BIO-106 — Medical literacy](../BIO-106/syllabus.md)

## Lesson blueprints

### L01 — Ageing and function

- **Outcome:** Explain ageing and function in the context of ageing and preventive care.
- **Example brief:** Use a realistic fictional case involving ageing and function; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to preventive care question list.
- **Knowledge check:** Explain ageing and function from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of ageing and function; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-108.L01`

### L02 — Prevention

- **Outcome:** Compare and distinguish prevention in the context of ageing and preventive care.
- **Example brief:** Use a realistic fictional case involving prevention; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to preventive care question list.
- **Knowledge check:** Explain prevention from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of prevention; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-108.L02`

### L03 — Screening trade-offs

- **Outcome:** Apply screening trade-offs in the context of ageing and preventive care.
- **Example brief:** Use a realistic fictional case involving screening trade-offs; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to preventive care question list.
- **Knowledge check:** Explain screening trade-offs from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of screening trade-offs; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-108.L03`

### L04 — Continuity of care

- **Outcome:** Evaluate and justify decisions about continuity of care in the context of ageing and preventive care.
- **Example brief:** Use a realistic fictional case involving continuity of care; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to preventive care question list.
- **Knowledge check:** Explain continuity of care from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of continuity of care; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-108.L04`
