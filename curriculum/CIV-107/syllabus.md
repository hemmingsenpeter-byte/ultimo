# CIV-107 — Scientific revolutions

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [INT-104 — Scientific reasoning](../INT-104/syllabus.md)

## Lesson blueprints

### L01 — Scientific breakthroughs

- **Outcome:** Explain scientific breakthroughs in the context of scientific revolutions.
- **Example brief:** Use a realistic fictional case involving scientific breakthroughs; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to scientific history essay.
- **Knowledge check:** Explain scientific breakthroughs from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of scientific breakthroughs; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-107.L01`

### L02 — Evidence and paradigms

- **Outcome:** Compare and distinguish evidence and paradigms in the context of scientific revolutions.
- **Example brief:** Use a realistic fictional case involving evidence and paradigms; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to scientific history essay.
- **Knowledge check:** Explain evidence and paradigms from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of evidence and paradigms; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-107.L02`

### L03 — Technology adoption

- **Outcome:** Apply technology adoption in the context of scientific revolutions.
- **Example brief:** Use a realistic fictional case involving technology adoption; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to scientific history essay.
- **Knowledge check:** Explain technology adoption from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of technology adoption; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-107.L03`

### L04 — Social consequences

- **Outcome:** Evaluate and justify decisions about social consequences in the context of scientific revolutions.
- **Example brief:** Use a realistic fictional case involving social consequences; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to scientific history essay.
- **Knowledge check:** Explain social consequences from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of social consequences; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-107.L04`
