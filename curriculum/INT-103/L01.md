## Core teaching

Probability describes uncertainty about a defined event under a model. The sample space contains possible outcomes; an event is a subset. For equally likely outcomes, probability is favourable outcomes divided by total outcomes. Independent events have probabilities that do not change when the other occurs; mutually exclusive events cannot occur together. These concepts differ. For empirical forecasts the equal-likelihood assumption may fail, so explain the source of probabilities rather than treating them as facts.

## Framework

Define outcomes → mark event → state assumptions → count or estimate → check range 0–1. Use a table when events overlap.

This sequence is an instructional model, not a universal law. Check its limitations against the contrasting case.

## Worked example

A fair die has six outcomes. P(even)=3/6 and P(6)=1/6. Six is even, so P(even or 6)=3/6, not 4/6. The events overlap.

### Contrasting case

Rolling a one and a six on the same single roll are mutually exclusive, not independent: knowing one happened rules out the other.
