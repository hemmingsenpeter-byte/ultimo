## Core teaching

A base rate is the prevalence of an event in a relevant population before considering new evidence. Conditional probability asks about an event given information. Confusing P(positive given condition) with P(condition given positive) is a common error. Natural-frequency tables help because every number has a denominator. The following example is hypothetical and not medical advice; real tests require clinical interpretation.

## Framework

Start with a population → split by condition → apply conditional rates → count positives → divide true positives by all positives.

This sequence is an instructional model, not a universal law. Check its limitations against the contrasting case.

## Worked example

Of 1,000 hypothetical items, 10 are defective. A detector flags 9 of those and 99 of 990 sound items. There are 108 flags, only 9 true defects: 9/108=8.33%. High detection sensitivity alone does not imply most flags are true.

### Contrasting case

If defects were much more common with the same detector rates, the fraction of true flags would generally rise.

## Guided practice

For 1000 items, 100 defective, sensitivity 80%, false-positive rate 10%, compute flagged true fraction. Model: 80 true +90 false=170 flags; 80/170≈47.1%.
