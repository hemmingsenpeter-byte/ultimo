# SOC-108 — Networking

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [SOC-103 — Friendship and community](../SOC-103/syllabus.md)

## Lesson blueprints

### L01 — Reciprocal networks

- **Outcome:** Explain reciprocal networks in the context of networking.
- **Example brief:** Use a realistic fictional case involving reciprocal networks; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to ethical networking plan.
- **Knowledge check:** Explain reciprocal networks from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of reciprocal networks; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-108.L01`

### L02 — Low-pressure requests

- **Outcome:** Compare and distinguish low-pressure requests in the context of networking.
- **Example brief:** Use a realistic fictional case involving low-pressure requests; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to ethical networking plan.
- **Knowledge check:** Explain low-pressure requests from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of low-pressure requests; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-108.L02`

### L03 — Consent-based introductions

- **Outcome:** Apply consent-based introductions in the context of networking.
- **Example brief:** Use a realistic fictional case involving consent-based introductions; show reasoning, a contrasting case and limitations.

### L04 — Follow-up
