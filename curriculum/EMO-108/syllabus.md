# EMO-108 — Empathy

Framework defined; lesson content: **draft**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites

## Lesson blueprints

### L01 — Perspective-taking

- **Outcome:** Explain perspective-taking in the context of empathy.
- **Example brief:** Use a realistic fictional case involving perspective-taking; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to listening role-play.
- **Knowledge check:** Explain perspective-taking from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of perspective-taking; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-108.L01`

### L02 — Reflective listening

- **Outcome:** Compare and distinguish reflective listening in the context of empathy.
- **Example brief:** Use a realistic fictional case involving reflective listening; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to listening role-play.
- **Knowledge check:** Explain reflective listening from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of reflective listening; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-108.L02`

### L03 — Empathy versus agreement

- **Outcome:** Apply empathy versus agreement in the context of empathy.
- **Example brief:** Use a realistic fictional case involving empathy versus agreement; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to listening role-play.
- **Knowledge check:** Explain empathy versus agreement from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of empathy versus agreement; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-108.L03`

### L04 — Compassionate limits

- **Outcome:** Evaluate and justify decisions about compassionate limits in the context of empathy.
- **Example brief:** Use a realistic fictional case involving compassionate limits; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to listening role-play.
- **Knowledge check:** Explain compassionate limits from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of compassionate limits; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-108.L04`
