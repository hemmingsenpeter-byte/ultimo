# BIO-101 — Human biology

Framework defined; lesson content: **planned**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
None; prior learning may be demonstrated.

## Lesson blueprints

### L01 — Cells and tissues

- **Outcome:** Explain cells and tissues in the context of human biology.
- **Example brief:** Use a realistic fictional case involving cells and tissues; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to organ-system diagram.
- **Knowledge check:** Explain cells and tissues from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of cells and tissues; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-101.L01`

### L02 — Circulation and respiration

- **Outcome:** Compare and distinguish circulation and respiration in the context of human biology.
- **Example brief:** Use a realistic fictional case involving circulation and respiration; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to organ-system diagram.
- **Knowledge check:** Explain circulation and respiration from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of circulation and respiration; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-101.L02`

### L03 — Digestion and kidneys

- **Outcome:** Apply digestion and kidneys in the context of human biology.
- **Example brief:** Use a realistic fictional case involving digestion and kidneys; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to organ-system diagram.
- **Knowledge check:** Explain digestion and kidneys from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of digestion and kidneys; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-101.L03`

### L04 — Homeostasis

- **Outcome:** Evaluate and justify decisions about homeostasis in the context of human biology.
- **Example brief:** Use a realistic fictional case involving homeostasis; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to organ-system diagram.
- **Knowledge check:** Explain homeostasis from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of homeostasis; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-101.L04`
