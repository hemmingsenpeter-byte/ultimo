# PRA-108 — Digital security

Framework defined; lesson content: **planned**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
None; prior learning may be demonstrated.

## Lesson blueprints

### L01 — Authentication and threats

- **Outcome:** Explain authentication and threats in the context of digital security.
- **Example brief:** Use a realistic fictional case involving authentication and threats; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to fictional account security audit.
- **Knowledge check:** Explain authentication and threats from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of authentication and threats; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-108.L01`

### L02 — Passwords and MFA

- **Outcome:** Compare and distinguish passwords and MFA in the context of digital security.
- **Example brief:** Use a realistic fictional case involving passwords and mfa; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to fictional account security audit.
- **Knowledge check:** Explain passwords and mfa from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of passwords and mfa; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-108.L02`

### L03 — Phishing and backups

- **Outcome:** Apply phishing and backups in the context of digital security.
