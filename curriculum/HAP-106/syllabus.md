# HAP-106 — Meaning and purpose

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [PHI-105 — Ethics](../PHI-105/syllabus.md)

## Lesson blueprints

### L01 — Meaning and purpose

- **Outcome:** Explain meaning and purpose in the context of meaning and purpose.
- **Example brief:** Use a realistic fictional case involving meaning and purpose; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to values-to-action proposal.
- **Knowledge check:** Explain meaning and purpose from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of meaning and purpose; correct application to a new case; clear rationale and limits.
- **Competency ID:** `HAP-106.L01`

### L02 — Cultural variation

- **Outcome:** Compare and distinguish cultural variation in the context of meaning and purpose.
- **Example brief:** Use a realistic fictional case involving cultural variation; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to values-to-action proposal.
- **Knowledge check:** Explain cultural variation from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of cultural variation; correct application to a new case; clear rationale and limits.
- **Competency ID:** `HAP-106.L02`

### L03 — Values and contribution

- **Outcome:** Apply values and contribution in the context of meaning and purpose.
- **Example brief:** Use a realistic fictional case involving values and contribution; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to values-to-action proposal.

- **Evidence:** Accurate explanation of values and contribution; correct application to a new case; clear rationale and limits.
- **Competency ID:** `HAP-106.L03`

### L04 — Adaptable projects

- **Outcome:** Evaluate and justify decisions about adaptable projects in the context of meaning and purpose.
- **Example brief:** Use a realistic fictional case involving adaptable projects; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to values-to-action proposal.
- **Knowledge check:** Explain adaptable projects from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of adaptable projects; correct application to a new case; clear rationale and limits.
- **Competency ID:** `HAP-106.L04`
