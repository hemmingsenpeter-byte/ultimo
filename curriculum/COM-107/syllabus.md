## Lesson blueprints

### L01 — Purpose and facts

- **Outcome:** Explain purpose and facts in the context of difficult conversations.
- **Example brief:** Use a realistic fictional case involving purpose and facts; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to difficult conversation simulation.
- **Knowledge check:** Explain purpose and facts from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of purpose and facts; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-107.L01`

### L02 — Observation versus interpretation

- **Outcome:** Compare and distinguish observation versus interpretation in the context of difficult conversations.
- **Example brief:** Use a realistic fictional case involving observation versus interpretation; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to difficult conversation simulation.
- **Knowledge check:** Explain observation versus interpretation from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of observation versus interpretation; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-107.L02`

### L03 — Constructive requests

- **Outcome:** Apply constructive requests in the context of difficult conversations.
- **Example brief:** Use a realistic fictional case involving constructive requests; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to difficult conversation simulation.
- **Knowledge check:** Explain constructive requests from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of constructive requests; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-107.L03`

### L04 — Repair

- **Outcome:** Evaluate and justify decisions about repair in the context of difficult conversations.
- **Example brief:** Use a realistic fictional case involving repair; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to difficult conversation simulation.
- **Knowledge check:** Explain repair from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of repair; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-107.L04`
