# INT-104 — Scientific reasoning

Framework defined; lesson content: **draft**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [INT-103 — Probability and statistics](../INT-103/syllabus.md)

## Lesson blueprints

### L01 — Hypotheses

- **Outcome:** Explain hypotheses in the context of scientific reasoning.
- **Example brief:** Use a realistic fictional case involving hypotheses; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to experiment protocol.
- **Knowledge check:** Explain hypotheses from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of hypotheses; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-104.L01`

### L02 — Controls and confounding

- **Outcome:** Compare and distinguish controls and confounding in the context of scientific reasoning.
- **Example brief:** Use a realistic fictional case involving controls and confounding; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to experiment protocol.
- **Knowledge check:** Explain controls and confounding from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of controls and confounding; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-104.L02`

### L03 — Causal inference

- **Outcome:** Apply causal inference in the context of scientific reasoning.
- **Example brief:** Use a realistic fictional case involving causal inference; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to experiment protocol.
- **Knowledge check:** Explain causal inference from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of causal inference; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-104.L03`

### L04 — Replication

- **Outcome:** Evaluate and justify decisions about replication in the context of scientific reasoning.
- **Example brief:** Use a realistic fictional case involving replication; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to experiment protocol.
- **Knowledge check:** Explain replication from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of replication; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-104.L04`
