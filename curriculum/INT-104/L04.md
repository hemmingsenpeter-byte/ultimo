# INT-104 / L04 — Replication

**Draft — independent review pending.** Outcome: Evaluate and justify decisions about replication in the context of scientific reasoning.

## Orientation and retrieval

Recall the difference between finding an association and establishing a credible causal contrast. Why might a second team obtain a different result using a similar protocol?

## Core teaching

In the National Academies' 2019 terminology, computational reproducibility concerns obtaining consistent results from the same data and analysis methods; replicability concerns consistent findings across studies addressing a similar question using newly collected data. Other fields sometimes use these words differently. A replication can fail because of sampling variation, changed context, measurement differences, implementation error or an incorrect original conclusion. Conversely, repeated consistent findings can share a bias. Report effect estimates and uncertainty rather than reducing results to a binary pass or fail, and examine whether differences are meaningful for the question. Transparent protocols, measurement definitions, analysis decisions and versioned data or synthetic examples make checking possible. Preregistration can distinguish planned tests from exploratory analysis, but does not by itself establish quality.

## Framework

Use the repeatability packet: research question; protocol and materials; measurement definitions; analysis plan; data provenance and permissions; deviations; results and uncertainty. First ask whether the same inputs yield the stated result, then ask whether new observations under a comparable protocol support a similar conclusion. Keep privacy-sensitive data out of public materials.

## Worked example

A fictional team tests two search interfaces using synthetic files. They publish task descriptions, time rules and code that summarises the results. A second analyst runs the code on the original permitted data and obtains the same summary: computational reproduction. A separate team runs equivalent tasks using new synthetic files and observes a smaller effect: replication evidence. Compare familiarity, difficulty and uncertainty before declaring the original wrong.

### Contrasting case

Running the same script repeatedly on the same data is not an independent replication. A new study using a different outcome can answer a useful question but may not directly test the original finding.

## Guided practice

Create a one-page repeatability packet for the filing experiment. Model: freeze the protocol, define the time and accuracy metrics, list synthetic documents and random allocation procedure, state the planned comparison, record deviations and specify how a new dataset would be collected. Identify one privacy safeguard and one contextual limitation.

Attempt the task before reading the model; compare your reasoning, correct one concrete gap and retry.

## Independent transfer

Exchange a synthetic-data protocol with another learner or simulate a second study yourself. Record deviations and explain how a different estimate should change your confidence, without claiming definitive proof or disproof.
