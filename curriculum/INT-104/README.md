# INT-104 — Scientific reasoning

Draft · Year 1 · Level 2 guided practice · 6 indicative study hours. Not accredited. [Syllabus](syllabus.md).

## Outcomes
- Explain hypotheses in the context of scientific reasoning.
- Compare and distinguish controls and confounding in the context of scientific reasoning.
- Apply causal inference in the context of scientific reasoning.
- Evaluate and justify decisions about replication in the context of scientific reasoning.
