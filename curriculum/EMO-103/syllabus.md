# EMO-103 — Emotional regulation

Framework defined; lesson content: **draft**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [EMO-101 — Emotional identification](../EMO-101/syllabus.md)

## Lesson blueprints

### L01 — Triggers and appraisals

- **Outcome:** Explain triggers and appraisals in the context of emotional regulation.
- **Example brief:** Use a realistic fictional case involving triggers and appraisals; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to conflict simulation.
- **Knowledge check:** Explain triggers and appraisals from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of triggers and appraisals; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-103.L01`

### L02 — Alternative interpretations

- **Outcome:** Compare and distinguish alternative interpretations in the context of emotional regulation.
- **Example brief:** Use a realistic fictional case involving alternative interpretations; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to conflict simulation.
- **Knowledge check:** Explain alternative interpretations from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of alternative interpretations; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-103.L02`

### L03 — Regulation strategies

- **Outcome:** Apply regulation strategies in the context of emotional regulation.
- **Example brief:** Use a realistic fictional case involving regulation strategies; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to conflict simulation.
- **Knowledge check:** Explain regulation strategies from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of regulation strategies; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-103.L03`

### L04 — Constructive responses

- **Outcome:** Evaluate and justify decisions about constructive responses in the context of emotional regulation.
- **Example brief:** Use a realistic fictional case involving constructive responses; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to conflict simulation.
- **Knowledge check:** Explain constructive responses from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of constructive responses; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-103.L04`
