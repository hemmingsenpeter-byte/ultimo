# EMO-101 / L03 — Needs

## Core teaching

Emotions can draw attention to concerns, but the underlying need is a hypothesis to explore, not something reliably decoded from a single label. Frustration might relate to clarity, fairness, rest or an unmet expectation. Needs differ from demands: wanting predictability does not entitle someone to control another person's schedule. Name the concern and consider options that preserve both parties' choices. Some emotions have multiple causes and require no immediate resolution.

## Framework

Feeling → possible concern → evidence → request or self-directed action → respect refusal. Keep the request specific.

This sequence is an instructional model, not a universal law. Check its limitations against the contrasting case.

## Worked example

A friend cancels dinner twice. A learner identifies disappointment and a desire for reliability. They ask whether a different day is more realistic, instead of demanding immediate compliance.

### Contrasting case

Jealousy is not permission to inspect another person's messages. A concern can be discussed without surveillance or control.

## Guided practice

In a fictional missed deadline, list two possible concerns and one respectful request. Model: clarity and workload; ask for a revised delivery date and constraints.

Attempt the exercise before comparing to the model answer. Correct one specific gap.

## Independent transfer

Analyse a fictional disagreement about shared space; distinguish need, preference and demand.
