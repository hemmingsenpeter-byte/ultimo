# EMO-101 — Emotional identification

Framework defined; lesson content: **draft**. Year 1; Level 2 guided practice; Level 3 extension; 6 indicative study hours. [Read the course](README.md).

## Prerequisites
None.

## Lesson blueprints and authored materials
### [L01 — Emotion labels](L01.md)

- **Outcome:** Explain emotion labels in the context of emotional identification.
- **Example brief:** Use a realistic fictional case involving emotion labels; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to fictional emotion map.
- **Knowledge check:** Explain emotion labels from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of emotion labels; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-101.L01`

## Assessment
Fictional emotion map. All mapped criteria at level 2; no averaging away missing criteria. Level 3 requires independent novel application, delayed reassessment and appropriate review. Equivalent accessible written, oral, visual, simulated or supervised evidence; no personal disclosure required.

**Review:** psychology reviewer. Draft educational framework only. Use fictional cases; no personal diagnosis, prescription, hazardous practice, financial/legal instruction or unqualified certification. Obtain qualified/local review before publication.
