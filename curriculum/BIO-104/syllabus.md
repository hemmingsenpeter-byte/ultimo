# BIO-104 — Endocrinology and male physiology

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours.

## Lesson blueprints

### L01 — Hormone signalling

- **Outcome:** Explain hormone signalling in the context of endocrinology and male physiology.
- **Example brief:** Use a realistic fictional case involving hormone signalling; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to endocrine map and clinician questions.
- **Knowledge check:** Explain hormone signalling from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of hormone signalling; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-104.L01`
