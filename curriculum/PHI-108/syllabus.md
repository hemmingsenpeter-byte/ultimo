# PHI-108 — Practical judgement

Framework defined; lesson content: **planned**. Year 5; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [PHI-105 — Ethics](../PHI-105/syllabus.md)

## Lesson blueprints

### L01 — Rules and judgement

- **Outcome:** Explain rules and judgement in the context of practical judgement.
- **Example brief:** Use a realistic fictional case involving rules and judgement; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to judgement case portfolio.
- **Knowledge check:** Explain rules and judgement from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of rules and judgement; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHI-108.L01`

### L02 — Conflicting duties

- **Outcome:** Compare and distinguish conflicting duties in the context of practical judgement.
- **Example brief:** Use a realistic fictional case involving conflicting duties; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to judgement case portfolio.
- **Knowledge check:** Explain conflicting duties from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of conflicting duties; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHI-108.L02`

### L03 — Proportionality

- **Outcome:** Apply proportionality in the context of practical judgement.
- **Example brief:** Use a realistic fictional case involving proportionality; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to judgement case portfolio.
- **Knowledge check:** Explain proportionality from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of proportionality; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHI-108.L03`

### L04 — Consequences

- **Outcome:** Evaluate and justify decisions about consequences in the context of practical judgement.
- **Example brief:** Use a realistic fictional case involving consequences; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to judgement case portfolio.
- **Knowledge check:** Explain consequences from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of consequences; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHI-108.L04`
