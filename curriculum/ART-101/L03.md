## Core teaching

Value describes how light or dark a tone appears. Contrast is the difference between elements; strong contrast can attract attention, though placement and context also matter. Composition organises visual elements into relationships. Balance concerns distribution of visual weight and can be symmetrical or asymmetrical. A simple value study using a few tones makes large patterns easier to inspect before adding detail. There is no universal rule that every image needs a central focal point.

## Framework

Select three values → block large masses → choose emphasis → inspect balance → revise. Test the image at thumbnail size.

This sequence is an instructional model, not a universal law. Check its limitations against the contrasting case.

## Worked example

A sketch of a cup on a table uses light paper, middle-grey tabletop and dark shadow. The cup edge against the dark region attracts attention. Moving the shadow changes the balance without changing the subject.

### Contrasting case

Adding detailed texture everywhere may weaken a desired emphasis by making all areas compete; in other styles that complexity may be intentional.

## Guided practice

Make two thumbnails of the same objects using only light, mid and dark values. Model: move the darkest area between versions and describe how attention changes.

Attempt the exercise before comparing to the model answer. Correct one specific gap.

## Independent transfer

Create a tonal study with an explicit composition intention and compare it to a deliberately different arrangement.
