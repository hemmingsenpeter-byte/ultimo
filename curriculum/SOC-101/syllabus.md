# SOC-101 — Conversation

Framework defined; lesson content: **planned**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
None; prior learning may be demonstrated.

## Lesson blueprints

### L01 — Open questions

- **Outcome:** Explain open questions in the context of conversation.
- **Example brief:** Use a realistic fictional case involving open questions; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to conversation role-play.
- **Knowledge check:** Explain open questions from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of open questions; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-101.L01`

### L02 — Turn-taking

- **Outcome:** Compare and distinguish turn-taking in the context of conversation.
- **Example brief:** Use a realistic fictional case involving turn-taking; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to conversation role-play.
- **Knowledge check:** Explain turn-taking from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of turn-taking; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-101.L02`

### L03 — Conversational repair

- **Outcome:** Apply conversational repair in the context of conversation.
- **Example brief:** Use a realistic fictional case involving conversational repair; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to conversation role-play.
- **Knowledge check:** Explain conversational repair from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of conversational repair; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-101.L03`

### L04 — Closing respectfully

- **Outcome:** Evaluate and justify decisions about closing respectfully in the context of conversation.
- **Example brief:** Use a realistic fictional case involving closing respectfully; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to conversation role-play.
- **Knowledge check:** Explain closing respectfully from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of closing respectfully; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-101.L04`
