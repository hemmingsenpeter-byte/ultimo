# SOC-106 — Group dynamics

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [SOC-102 — Social awareness](../SOC-102/syllabus.md)

## Lesson blueprints

### L01 — Roles and norms

- **Outcome:** Explain roles and norms in the context of group dynamics.
- **Example brief:** Use a realistic fictional case involving roles and norms; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to meeting facilitation plan.
- **Knowledge check:** Explain roles and norms from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of roles and norms; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-106.L01`

### L02 — Conformity

- **Outcome:** Compare and distinguish conformity in the context of group dynamics.
- **Example brief:** Use a realistic fictional case involving conformity; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to meeting facilitation plan.
- **Knowledge check:** Explain conformity from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of conformity; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-106.L02`

### L03 — Facilitation

- **Outcome:** Apply facilitation in the context of group dynamics.
- **Example brief:** Use a realistic fictional case involving facilitation; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to meeting facilitation plan.
- **Knowledge check:** Explain facilitation from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of facilitation; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-106.L03`

### L04 — Inclusion

- **Outcome:** Evaluate and justify decisions about inclusion in the context of group dynamics.
- **Example brief:** Use a realistic fictional case involving inclusion; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to meeting facilitation plan.
- **Knowledge check:** Explain inclusion from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of inclusion; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-106.L04`
