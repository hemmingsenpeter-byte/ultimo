# PHI-102 — Stoicism and Epicureanism

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [PHI-101 — Ancient Greek philosophy](../PHI-101/syllabus.md)

## Lesson blueprints

### L01 — Stoic aims

- **Outcome:** Explain stoic aims in the context of stoicism and epicureanism.
- **Example brief:** Use a realistic fictional case involving stoic aims; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to two-perspective dilemma.
- **Knowledge check:** Explain stoic aims from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of stoic aims; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHI-102.L01`

### L02 — Epicurean aims

- **Outcome:** Compare and distinguish epicurean aims in the context of stoicism and epicureanism.
- **Example brief:** Use a realistic fictional case involving epicurean aims; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to two-perspective dilemma.
- **Knowledge check:** Explain epicurean aims from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of epicurean aims; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHI-102.L02`

### L03 — Control and influence

- **Outcome:** Apply control and influence in the context of stoicism and epicureanism.
- **Example brief:** Use a realistic fictional case involving control and influence; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to two-perspective dilemma.
- **Knowledge check:** Explain control and influence from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of control and influence; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHI-102.L03`

### L04 — Practical limits

- **Outcome:** Evaluate and justify decisions about practical limits in the context of stoicism and epicureanism.
- **Example brief:** Use a realistic fictional case involving practical limits; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to two-perspective dilemma.
- **Knowledge check:** Explain practical limits from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of practical limits; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHI-102.L04`
