# HAP-102 — Gratitude and contentment

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours.

## Lesson blueprints

### L01 — Gratitude versus forced positivity

- **Outcome:** Explain gratitude versus forced positivity in the context of gratitude and contentment.
- **Example brief:** Use a realistic fictional case involving gratitude versus forced positivity; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to voluntary appreciation experiment.
- **Knowledge check:** Explain gratitude versus forced positivity from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of gratitude versus forced positivity; correct application to a new case; clear rationale and limits.
- **Competency ID:** `HAP-102.L01`
