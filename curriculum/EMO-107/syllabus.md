# EMO-107 — Grief and vulnerability

Framework defined; lesson content: **draft**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites

## Lesson blueprints

### L01 — Grief variability

- **Outcome:** Explain grief variability in the context of grief and vulnerability.
- **Example brief:** Use a realistic fictional case involving grief variability; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to fictional bereavement support plan.
- **Knowledge check:** Explain grief variability from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of grief variability; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-107.L01`

### L02 — Cultural context
