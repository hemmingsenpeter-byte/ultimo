# SOC-105 — Charisma and humour

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [COM-104 — Storytelling](../COM-104/syllabus.md)

## Lesson blueprints

### L01 — Warmth and attention

- **Outcome:** Explain warmth and attention in the context of charisma and humour.
- **Example brief:** Use a realistic fictional case involving warmth and attention; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to introduction and feedback.
- **Knowledge check:** Explain warmth and attention from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of warmth and attention; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-105.L01`

### L02 — Humour

- **Outcome:** Compare and distinguish humour in the context of charisma and humour.
- **Example brief:** Use a realistic fictional case involving humour; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to introduction and feedback.
- **Knowledge check:** Explain humour from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of humour; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-105.L02`

### L03 — Engaging stories

- **Outcome:** Apply engaging stories in the context of charisma and humour.
- **Example brief:** Use a realistic fictional case involving engaging stories; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to introduction and feedback.
- **Knowledge check:** Explain engaging stories from memory and apply it to a different example; state one limitation.

### L04 — Authenticity

- **Outcome:** Evaluate and justify decisions about authenticity in the context of charisma and humour.
- **Example brief:** Use a realistic fictional case involving authenticity; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to introduction and feedback.
- **Knowledge check:** Explain authenticity from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of authenticity; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-105.L04`
