# COM-104 — Storytelling

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [COM-102 — Writing](../COM-102/syllabus.md)

## Lesson blueprints

### L01 — Narrative purpose

- **Outcome:** Explain narrative purpose in the context of storytelling.
- **Example brief:** Use a realistic fictional case involving narrative purpose; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to original story.
- **Knowledge check:** Explain narrative purpose from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of narrative purpose; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-104.L01`

### L02 — Sequence and stakes

- **Outcome:** Compare and distinguish sequence and stakes in the context of storytelling.
- **Example brief:** Use a realistic fictional case involving sequence and stakes; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to original story.
- **Knowledge check:** Explain sequence and stakes from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of sequence and stakes; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-104.L02`

### L03 — Concrete detail

- **Outcome:** Apply concrete detail in the context of storytelling.
- **Example brief:** Use a realistic fictional case involving concrete detail; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to original story.
- **Knowledge check:** Explain concrete detail from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of concrete detail; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-104.L03`

### L04 — Feedback

- **Outcome:** Evaluate and justify decisions about feedback in the context of storytelling.
- **Example brief:** Use a realistic fictional case involving feedback; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to original story.
- **Knowledge check:** Explain feedback from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of feedback; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-104.L04`
