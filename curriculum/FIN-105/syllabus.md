## Lesson blueprints

### L01 — Asset classes

- **Outcome:** Explain asset classes in the context of investing.
- **Example brief:** Use a realistic fictional case involving asset classes; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to fictional investment policy.
- **Knowledge check:** Explain asset classes from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of asset classes; correct application to a new case; clear rationale and limits.
- **Competency ID:** `FIN-105.L01`

### L02 — Diversification and fees

- **Outcome:** Compare and distinguish diversification and fees in the context of investing.
- **Example brief:** Use a realistic fictional case involving diversification and fees; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to fictional investment policy.
- **Knowledge check:** Explain diversification and fees from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of diversification and fees; correct application to a new case; clear rationale and limits.
- **Competency ID:** `FIN-105.L02`

### L03 — Compounding

- **Outcome:** Apply compounding in the context of investing.
- **Example brief:** Use a realistic fictional case involving compounding; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to fictional investment policy.
- **Knowledge check:** Explain compounding from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of compounding; correct application to a new case; clear rationale and limits.
- **Competency ID:** `FIN-105.L03`

### L04 — Investment policy

- **Outcome:** Evaluate and justify decisions about investment policy in the context of investing.
- **Example brief:** Use a realistic fictional case involving investment policy; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to fictional investment policy.
- **Knowledge check:** Explain investment policy from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of investment policy; correct application to a new case; clear rationale and limits.
- **Competency ID:** `FIN-105.L04`
