# CIV-101 — World history

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [INT-104 — Scientific reasoning](../INT-104/syllabus.md)

## Lesson blueprints

### L01 — Historical chronology

- **Outcome:** Explain historical chronology in the context of world history.
- **Example brief:** Use a realistic fictional case involving historical chronology; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to comparative timeline.
- **Knowledge check:** Explain historical chronology from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of historical chronology; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-101.L01`

### L02 — Primary and secondary sources

- **Outcome:** Compare and distinguish primary and secondary sources in the context of world history.
- **Example brief:** Use a realistic fictional case involving primary and secondary sources; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to comparative timeline.
- **Knowledge check:** Explain primary and secondary sources from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of primary and secondary sources; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-101.L02`

### L03 — Trade and migration

- **Outcome:** Apply trade and migration in the context of world history.
- **Example brief:** Use a realistic fictional case involving trade and migration; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to comparative timeline.
- **Knowledge check:** Explain trade and migration from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of trade and migration; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-101.L03`

### L04 — Competing interpretations

- **Outcome:** Evaluate and justify decisions about competing interpretations in the context of world history.
- **Example brief:** Use a realistic fictional case involving competing interpretations; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to comparative timeline.
- **Knowledge check:** Explain competing interpretations from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of competing interpretations; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-101.L04`
