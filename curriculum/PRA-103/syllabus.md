# PRA-103 — Household maintenance

Framework defined; lesson content: **planned**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
None; prior learning may be demonstrated.

## Lesson blueprints

### L01 — Building systems

- **Outcome:** Explain building systems in the context of household maintenance.
- **Example brief:** Use a realistic fictional case involving building systems; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to home maintenance register.
- **Knowledge check:** Explain building systems from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of building systems; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-103.L01`

### L02 — Observation versus diagnosis

- **Outcome:** Compare and distinguish observation versus diagnosis in the context of household maintenance.
- **Example brief:** Use a realistic fictional case involving observation versus diagnosis; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to home maintenance register.
- **Knowledge check:** Explain observation versus diagnosis from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of observation versus diagnosis; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-103.L02`

### L03 — Maintenance priorities

- **Outcome:** Apply maintenance priorities in the context of household maintenance.
- **Example brief:** Use a realistic fictional case involving maintenance priorities; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to home maintenance register.
- **Knowledge check:** Explain maintenance priorities from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of maintenance priorities; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-103.L03`

### L04 — Licensed trades

- **Outcome:** Evaluate and justify decisions about licensed trades in the context of household maintenance.
- **Example brief:** Use a realistic fictional case involving licensed trades; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to home maintenance register.
- **Knowledge check:** Explain licensed trades from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of licensed trades; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-103.L04`
