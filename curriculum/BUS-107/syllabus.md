# BUS-107 — Product development

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours.

## Lesson blueprints

### L01 — Problem framing

- **Outcome:** Explain problem framing in the context of product development.
- **Example brief:** Use a realistic fictional case involving problem framing; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to prototype and test plan.
- **Knowledge check:** Explain problem framing from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of problem framing; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-107.L01`

### L02 — Prototypes

- **Outcome:** Compare and distinguish prototypes in the context of product development.
- **Example brief:** Use a realistic fictional case involving prototypes; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to prototype and test plan.
- **Knowledge check:** Explain prototypes from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of prototypes; correct application to a new case; clear rationale and limits.

### L03 — User testing

- **Outcome:** Apply user testing in the context of product development.
- **Example brief:** Use a realistic fictional case involving user testing; show reasoning, a contrasting case and limitations.

### L04 — Iteration

- **Outcome:** Evaluate and justify decisions about iteration in the context of product development.
