## Lesson blueprints

### L01 — Attention limits

- **Outcome:** Explain attention limits in the context of attention and concentration.
- **Example brief:** Use a realistic fictional case involving attention limits; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to attention audit.
- **Knowledge check:** Explain attention limits from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of attention limits; correct application to a new case; clear rationale and limits.
- **Competency ID:** `MEN-102.L01`
