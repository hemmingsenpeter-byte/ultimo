# ART-105 — Architecture and design

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [ART-101 — Drawing and observation](../ART-101/syllabus.md)

## Lesson blueprints

### L01 — Form and function

- **Outcome:** Explain form and function in the context of architecture and design.
- **Example brief:** Use a realistic fictional case involving form and function; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to annotated spatial concept.
- **Knowledge check:** Explain form and function from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of form and function; correct application to a new case; clear rationale and limits.
- **Competency ID:** `ART-105.L01`

### L02 — Materials and circulation

- **Outcome:** Compare and distinguish materials and circulation in the context of architecture and design.
- **Example brief:** Use a realistic fictional case involving materials and circulation; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to annotated spatial concept.
- **Knowledge check:** Explain materials and circulation from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of materials and circulation; correct application to a new case; clear rationale and limits.
- **Competency ID:** `ART-105.L02`

### L03 — Accessibility

- **Outcome:** Apply accessibility in the context of architecture and design.
- **Example brief:** Use a realistic fictional case involving accessibility; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to annotated spatial concept.
- **Knowledge check:** Explain accessibility from memory and apply it to a different example; state one limitation.

- **Competency ID:** `ART-105.L03`

### L04 — Design response

- **Outcome:** Evaluate and justify decisions about design response in the context of architecture and design.
- **Example brief:** Use a realistic fictional case involving design response; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to annotated spatial concept.
- **Knowledge check:** Explain design response from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of design response; correct application to a new case; clear rationale and limits.
- **Competency ID:** `ART-105.L04`
