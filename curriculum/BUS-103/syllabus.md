# BUS-103 — Sales

## Lesson blueprints

### L01 — Customer problems

- **Outcome:** Explain customer problems in the context of sales.
- **Example brief:** Use a realistic fictional case involving customer problems; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to sales role-play.
- **Knowledge check:** Explain customer problems from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of customer problems; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-103.L01`

### L02 — Ethical discovery

- **Outcome:** Compare and distinguish ethical discovery in the context of sales.
- **Example brief:** Use a realistic fictional case involving ethical discovery; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to sales role-play.
- **Knowledge check:** Explain ethical discovery from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of ethical discovery; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-103.L02`

### L03 — Value proposition

- **Outcome:** Apply value proposition in the context of sales.
- **Example brief:** Use a realistic fictional case involving value proposition; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to sales role-play.
- **Knowledge check:** Explain value proposition from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of value proposition; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-103.L03`

### L04 — Objections

- **Outcome:** Evaluate and justify decisions about objections in the context of sales.
- **Example brief:** Use a realistic fictional case involving objections; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to sales role-play.
- **Knowledge check:** Explain objections from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of objections; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-103.L04`
