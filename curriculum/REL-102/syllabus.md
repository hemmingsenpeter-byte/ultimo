# REL-102 — Attachment and compatibility

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [EMO-105 — Attachment and development](../EMO-105/syllabus.md)

## Lesson blueprints

### L01 — Attachment patterns

- **Outcome:** Explain attachment patterns in the context of attachment and compatibility.
- **Example brief:** Use a realistic fictional case involving attachment patterns; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to compatibility conversation.
- **Knowledge check:** Explain attachment patterns from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of attachment patterns; correct application to a new case; clear rationale and limits.
- **Competency ID:** `REL-102.L01`

### L02 — Compatibility dimensions

- **Outcome:** Compare and distinguish compatibility dimensions in the context of attachment and compatibility.
- **Example brief:** Use a realistic fictional case involving compatibility dimensions; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to compatibility conversation.
- **Knowledge check:** Explain compatibility dimensions from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of compatibility dimensions; correct application to a new case; clear rationale and limits.
- **Competency ID:** `REL-102.L02`

### L03 — Needs

- **Outcome:** Apply needs in the context of attachment and compatibility.

### L04 — Boundaries

- **Outcome:** Evaluate and justify decisions about boundaries in the context of attachment and compatibility.
