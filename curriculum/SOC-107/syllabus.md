# SOC-107 — Etiquette and presentation

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [SOC-101 — Conversation](../SOC-101/syllabus.md)

## Lesson blueprints

### L01 — Contextual etiquette

- **Outcome:** Explain contextual etiquette in the context of etiquette and presentation.
- **Example brief:** Use a realistic fictional case involving contextual etiquette; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to event checklist.
- **Knowledge check:** Explain contextual etiquette from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of contextual etiquette; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-107.L01`

### L02 — Presentation

- **Outcome:** Compare and distinguish presentation in the context of etiquette and presentation.
- **Example brief:** Use a realistic fictional case involving presentation; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to event checklist.
- **Knowledge check:** Explain presentation from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of presentation; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-107.L02`

### L03 — Hosting

- **Outcome:** Apply hosting in the context of etiquette and presentation.
- **Example brief:** Use a realistic fictional case involving hosting; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to event checklist.
- **Knowledge check:** Explain hosting from memory and apply it to a different example; state one limitation.

- **Competency ID:** `SOC-107.L03`

### L04 — Unfamiliar norms

- **Outcome:** Evaluate and justify decisions about unfamiliar norms in the context of etiquette and presentation.
- **Example brief:** Use a realistic fictional case involving unfamiliar norms; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to event checklist.
- **Knowledge check:** Explain unfamiliar norms from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of unfamiliar norms; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-107.L04`
