# LEA-106 — Power and institutions

Framework defined; lesson content: **planned**. Year 4; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [PHI-105 — Ethics](../PHI-105/syllabus.md)

## Lesson blueprints

### L01 — Formal and informal power

- **Outcome:** Explain formal and informal power in the context of power and institutions.
- **Example brief:** Use a realistic fictional case involving formal and informal power; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to stakeholder map.
- **Knowledge check:** Explain formal and informal power from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of formal and informal power; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-106.L01`

### L02 — Stakeholders

- **Outcome:** Compare and distinguish stakeholders in the context of power and institutions.
- **Example brief:** Use a realistic fictional case involving stakeholders; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to stakeholder map.
- **Knowledge check:** Explain stakeholders from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of stakeholders; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-106.L02`

### L03 — Accountability

- **Outcome:** Apply accountability in the context of power and institutions.
- **Example brief:** Use a realistic fictional case involving accountability; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to stakeholder map.
- **Knowledge check:** Explain accountability from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of accountability; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-106.L03`

### L04 — Ethical safeguards

- **Outcome:** Evaluate and justify decisions about ethical safeguards in the context of power and institutions.
- **Example brief:** Use a realistic fictional case involving ethical safeguards; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to stakeholder map.
- **Knowledge check:** Explain ethical safeguards from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of ethical safeguards; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-106.L04`
