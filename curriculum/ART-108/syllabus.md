# ART-108 — Aesthetic judgement

Framework defined; lesson content: **planned**. Year 5; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [ART-103 — Literature and poetry](../ART-103/syllabus.md)

## Lesson blueprints

### L01 — Formal qualities

- **Outcome:** Explain formal qualities in the context of aesthetic judgement.
- **Example brief:** Use a realistic fictional case involving formal qualities; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to curatorial portfolio.
- **Knowledge check:** Explain formal qualities from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of formal qualities; correct application to a new case; clear rationale and limits.
- **Competency ID:** `ART-108.L01`

### L02 — Cultural context

- **Outcome:** Compare and distinguish cultural context in the context of aesthetic judgement.
- **Example brief:** Use a realistic fictional case involving cultural context; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to curatorial portfolio.
- **Knowledge check:** Explain cultural context from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of cultural context; correct application to a new case; clear rationale and limits.
- **Competency ID:** `ART-108.L02`

### L03 — Aesthetic reasoning

- **Outcome:** Apply aesthetic reasoning in the context of aesthetic judgement.
- **Example brief:** Use a realistic fictional case involving aesthetic reasoning; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to curatorial portfolio.
- **Knowledge check:** Explain aesthetic reasoning from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of aesthetic reasoning; correct application to a new case; clear rationale and limits.
- **Competency ID:** `ART-108.L03`

### L04 — Curation

- **Outcome:** Evaluate and justify decisions about curation in the context of aesthetic judgement.
- **Example brief:** Use a realistic fictional case involving curation; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to curatorial portfolio.
- **Knowledge check:** Explain curation from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of curation; correct application to a new case; clear rationale and limits.
- **Competency ID:** `ART-108.L04`
