# PRA-104 — Tools and carpentry

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [PRA-103 — Household maintenance](../PRA-103/syllabus.md)

## Lesson blueprints

### L01 — Tools and materials

- **Outcome:** Explain tools and materials in the context of tools and carpentry.
- **Example brief:** Use a realistic fictional case involving tools and materials; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to low-risk project plan.
- **Knowledge check:** Explain tools and materials from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of tools and materials; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-104.L01`

### L02 — Measurement and joining

- **Outcome:** Compare and distinguish measurement and joining in the context of tools and carpentry.
- **Example brief:** Use a realistic fictional case involving measurement and joining; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to low-risk project plan.
- **Knowledge check:** Explain measurement and joining from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of measurement and joining; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-104.L02`

### L03 — Supervised project planning

- **Outcome:** Apply supervised project planning in the context of tools and carpentry.
- **Example brief:** Use a realistic fictional case involving supervised project planning; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to low-risk project plan.
- **Knowledge check:** Explain supervised project planning from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of supervised project planning; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-104.L03`

### L04 — Hazards

- **Outcome:** Evaluate and justify decisions about hazards in the context of tools and carpentry.
- **Example brief:** Use a realistic fictional case involving hazards; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to low-risk project plan.
- **Knowledge check:** Explain hazards from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of hazards; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PRA-104.L04`
