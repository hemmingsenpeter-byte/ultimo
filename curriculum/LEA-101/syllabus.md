# LEA-101 — Personal responsibility

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [PHI-105 — Ethics](../PHI-105/syllabus.md)

## Lesson blueprints

### L01 — Responsibility versus blame

- **Outcome:** Explain responsibility versus blame in the context of personal responsibility.
- **Example brief:** Use a realistic fictional case involving responsibility versus blame; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to accountability case.
- **Knowledge check:** Explain responsibility versus blame from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of responsibility versus blame; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-101.L01`

### L02 — Authority and obligations

- **Outcome:** Compare and distinguish authority and obligations in the context of personal responsibility.
- **Example brief:** Use a realistic fictional case involving authority and obligations; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to accountability case.
- **Knowledge check:** Explain authority and obligations from memory and apply it to a different example; state one limitation.

### L03 — Commitments
