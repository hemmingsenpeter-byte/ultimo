# COM-106 — Negotiation

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [COM-103 — Listening and questioning](../COM-103/syllabus.md)

## Lesson blueprints

### L01 — Interests and positions

- **Outcome:** Explain interests and positions in the context of negotiation.
- **Example brief:** Use a realistic fictional case involving interests and positions; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to negotiation simulation.
- **Knowledge check:** Explain interests and positions from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of interests and positions; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-106.L01`

### L02 — Alternatives

- **Outcome:** Compare and distinguish alternatives in the context of negotiation.
- **Example brief:** Use a realistic fictional case involving alternatives; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to negotiation simulation.
- **Knowledge check:** Explain alternatives from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of alternatives; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-106.L02`

### L03 — Objective criteria

- **Outcome:** Apply objective criteria in the context of negotiation.
- **Example brief:** Use a realistic fictional case involving objective criteria; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to negotiation simulation.
- **Knowledge check:** Explain objective criteria from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of objective criteria; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-106.L03`

### L04 — Agreement

- **Outcome:** Evaluate and justify decisions about agreement in the context of negotiation.
- **Example brief:** Use a realistic fictional case involving agreement; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to negotiation simulation.
- **Knowledge check:** Explain agreement from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of agreement; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-106.L04`
