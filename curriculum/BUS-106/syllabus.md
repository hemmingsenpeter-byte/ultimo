# BUS-106 — Operations

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours.

## Lesson blueprints

### L01 — Process mapping

- **Outcome:** Explain process mapping in the context of operations.
- **Example brief:** Use a realistic fictional case involving process mapping; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to process improvement proposal.
- **Knowledge check:** Explain process mapping from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of process mapping; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-106.L01`

### L02 — Capacity and throughput

- **Outcome:** Compare and distinguish capacity and throughput in the context of operations.
- **Example brief:** Use a realistic fictional case involving capacity and throughput; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to process improvement proposal.
- **Knowledge check:** Explain capacity and throughput from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of capacity and throughput; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-106.L02`

### L03 — Controls

- **Outcome:** Apply controls in the context of operations.
- **Example brief:** Use a realistic fictional case involving controls; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to process improvement proposal.
- **Knowledge check:** Explain controls from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of controls; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-106.L03`

### L04 — Improvement metrics

- **Outcome:** Evaluate and justify decisions about improvement metrics in the context of operations.
- **Example brief:** Use a realistic fictional case involving improvement metrics; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to process improvement proposal.
- **Knowledge check:** Explain improvement metrics from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of improvement metrics; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-106.L04`
