# INT-102 — Logic and argument

Framework defined; lesson content: **planned**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours.

## Lesson blueprints

### L01 — Premises and conclusions

- **Outcome:** Explain premises and conclusions in the context of logic and argument.
- **Example brief:** Use a realistic fictional case involving premises and conclusions; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to two-sided argument map.
- **Knowledge check:** Explain premises and conclusions from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of premises and conclusions; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-102.L01`
