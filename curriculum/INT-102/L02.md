# INT-102 / L02 — Validity and soundness

**Draft — independent review pending.** Outcome: Compare and distinguish validity and soundness in the context of logic and argument.

## Orientation and retrieval

Retrieve the difference between a premise and conclusion. Consider whether a conclusion can be true even when the reasoning used to reach it is defective.

## Core teaching

Deductive validity concerns structure: there must be no possible case in which all the premises hold and the conclusion fails. Soundness adds a requirement about the actual premises: a sound deductive argument is valid and has true premises. A valid argument can have a false premise and a true or false conclusion; an invalid argument can accidentally reach a true conclusion. To evaluate validity, provisionally grant the premises and try to construct a countermodel. To evaluate soundness, investigate the premises separately. Ordinary decisions frequently combine deductive steps with uncertain empirical estimates; a deductively valid subargument does not turn an estimate into certainty. Conditional statements are particularly useful. If A implies B and A is true, B follows. If A implies B and B is true, A need not follow because another cause or route may produce B.

## Framework

Run two gates: structure first, facts second. Translate the argument into simple symbols if the wording is confusing. Gate 1: assume premises true and look for a possible false conclusion. Gate 2: if valid, verify premises against the actual situation. Record either invalid, valid but unsound, sound, or valid with premise truth unresolved. Do not label inductive reasoning invalid merely because its conclusion is uncertain.

## Worked example

All reservations made before Friday receive a discount. The fictional booking was made on Thursday. Therefore it receives a discount. Given the stated rule and date, the structure is valid. Check the actual booking and whether the rule has exceptions. If the rule actually excludes weekends and this is a weekend booking, the first premise as stated is false; the argument is not sound.

### Contrasting case

If a booking was made before Friday, it receives a discount. This booking received a discount, so it was made before Friday. A loyalty discount is a possible countermodel: both premises hold while the conclusion fails. The argument affirms the consequent.

## Guided practice

Evaluate: (1) All copper objects conduct electricity; this object is copper; it conducts electricity. (2) All copper objects conduct electricity; this object conducts electricity; it is copper. Model: the first has valid form, with premise accuracy depending on conditions; the second is invalid because aluminium is a counterexample. Mark which gate fails.

Attempt the task before reading the model; compare your reasoning, correct one concrete gap and retry.

## Independent transfer

Construct one valid argument using a fictional organisational rule, one invalid reversal, and one valid argument with a deliberately false premise. Have a partner identify the distinction or use the countermodel method yourself.

## Knowledge check

1. What is the difference between validity and soundness?
2. Can an invalid argument have a true conclusion?
3. If A implies B and B holds, does A follow?

<details><summary>Answers (open after attempting)</summary>

1. Validity is the impossibility of true premises with a false conclusion; soundness also requires true premises. Test form and facts separately.
2. Yes; a correct conclusion may be reached by defective reasoning. Truth of a conclusion is not a structural test.
3. Not necessarily; B may arise another way. Provide a concrete countermodel.
