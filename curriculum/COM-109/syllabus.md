# COM-109 — Language acquisition

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites

## Lesson blueprints

### L01 — Functional goals

- **Outcome:** Explain functional goals in the context of language acquisition.
- **Example brief:** Use a realistic fictional case involving functional goals; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to language conversation.
- **Knowledge check:** Explain functional goals from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of functional goals; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-109.L01`

### L02 — Input and retrieval

- **Outcome:** Compare and distinguish input and retrieval in the context of language acquisition.
- **Example brief:** Use a realistic fictional case involving input and retrieval; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to language conversation.
- **Knowledge check:** Explain input and retrieval from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of input and retrieval; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-109.L02`

### L03 — Corrective feedback

- **Outcome:** Apply corrective feedback in the context of language acquisition.
- **Example brief:** Use a realistic fictional case involving corrective feedback; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to language conversation.
- **Knowledge check:** Explain corrective feedback from memory and apply it to a different example; state one limitation.

- **Competency ID:** `COM-109.L03`

### L04 — Contextual exchange

- **Outcome:** Evaluate and justify decisions about contextual exchange in the context of language acquisition.
- **Example brief:** Use a realistic fictional case involving contextual exchange; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to language conversation.

- **Evidence:** Accurate explanation of contextual exchange; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-109.L04`
