# REL-107 — Parenting

Framework defined; lesson content: **planned**. Year 4; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [REL-103 — Intimacy and consent](../REL-103/syllabus.md)

## Lesson blueprints

### L01 — Child development

- **Outcome:** Explain child development in the context of parenting.
- **Example brief:** Use a realistic fictional case involving child development; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to fictional caregiving plan.
- **Knowledge check:** Explain child development from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of child development; correct application to a new case; clear rationale and limits.
- **Competency ID:** `REL-107.L01`

### L02 — Responsive care

- **Outcome:** Compare and distinguish responsive care in the context of parenting.
- **Example brief:** Use a realistic fictional case involving responsive care; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to fictional caregiving plan.
- **Knowledge check:** Explain responsive care from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of responsive care; correct application to a new case; clear rationale and limits.
- **Competency ID:** `REL-107.L02`

### L03 — Nonviolent boundaries

- **Outcome:** Apply nonviolent boundaries in the context of parenting.
- **Example brief:** Use a realistic fictional case involving nonviolent boundaries; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to fictional caregiving plan.
- **Knowledge check:** Explain nonviolent boundaries from memory and apply it to a different example; state one limitation.

- **Competency ID:** `REL-107.L03`

### L04 — Safeguarding

- **Outcome:** Evaluate and justify decisions about safeguarding in the context of parenting.
- **Example brief:** Use a realistic fictional case involving safeguarding; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to fictional caregiving plan.
- **Knowledge check:** Explain safeguarding from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of safeguarding; correct application to a new case; clear rationale and limits.
- **Competency ID:** `REL-107.L04`
