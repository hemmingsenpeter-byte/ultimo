# LEA-104 — Coaching

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites

## Lesson blueprints

### L01 — Coaching versus directing

- **Outcome:** Explain coaching versus directing in the context of coaching.
- **Example brief:** Use a realistic fictional case involving coaching versus directing; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to coaching simulation.
- **Knowledge check:** Explain coaching versus directing from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of coaching versus directing; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-104.L01`

### L02 — Questions and feedback

- **Outcome:** Compare and distinguish questions and feedback in the context of coaching.
- **Example brief:** Use a realistic fictional case involving questions and feedback; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to coaching simulation.
- **Knowledge check:** Explain questions and feedback from memory and apply it to a different example; state one limitation.

### L03 — Development goals

- **Outcome:** Apply development goals in the context of coaching.

### L04 — Boundaries

- **Outcome:** Evaluate and justify decisions about boundaries in the context of coaching.
