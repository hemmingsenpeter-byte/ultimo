# HAP-103 — Mindfulness

Framework defined; lesson content: **planned**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
None; prior learning may be demonstrated.

## Lesson blueprints

### L01 — Awareness

- **Outcome:** Explain awareness in the context of mindfulness.
- **Example brief:** Use a realistic fictional case involving awareness; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to practice comparison.
- **Knowledge check:** Explain awareness from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of awareness; correct application to a new case; clear rationale and limits.
- **Competency ID:** `HAP-103.L01`

### L02 — Practice types and evidence

- **Outcome:** Compare and distinguish practice types and evidence in the context of mindfulness.
- **Example brief:** Use a realistic fictional case involving practice types and evidence; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to practice comparison.
- **Knowledge check:** Explain practice types and evidence from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of practice types and evidence; correct application to a new case; clear rationale and limits.
- **Competency ID:** `HAP-103.L02`

### L03 — Accessible exercises

- **Outcome:** Apply accessible exercises in the context of mindfulness.
- **Example brief:** Use a realistic fictional case involving accessible exercises; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to practice comparison.
- **Knowledge check:** Explain accessible exercises from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of accessible exercises; correct application to a new case; clear rationale and limits.
- **Competency ID:** `HAP-103.L03`

### L04 — Discomfort and alternatives

- **Outcome:** Evaluate and justify decisions about discomfort and alternatives in the context of mindfulness.
- **Example brief:** Use a realistic fictional case involving discomfort and alternatives; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to practice comparison.
- **Knowledge check:** Explain discomfort and alternatives from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of discomfort and alternatives; correct application to a new case; clear rationale and limits.
- **Competency ID:** `HAP-103.L04`
