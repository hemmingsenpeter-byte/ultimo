# INT-107 — Mathematics and science literacy

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [INT-103 — Probability and statistics](../INT-103/syllabus.md)

## Lesson blueprints

### L01 — Units and ratios

- **Outcome:** Explain units and ratios in the context of mathematics and science literacy.
- **Example brief:** Use a realistic fictional case involving units and ratios; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to quantitative problem set.
- **Knowledge check:** Explain units and ratios from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of units and ratios; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-107.L01`

### L02 — Linear and exponential models

- **Outcome:** Compare and distinguish linear and exponential models in the context of mathematics and science literacy.
- **Example brief:** Use a realistic fictional case involving linear and exponential models; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to quantitative problem set.
- **Knowledge check:** Explain linear and exponential models from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of linear and exponential models; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-107.L02`

### L03 — Graph interpretation

- **Outcome:** Apply graph interpretation in the context of mathematics and science literacy.
- **Example brief:** Use a realistic fictional case involving graph interpretation; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to quantitative problem set.
- **Knowledge check:** Explain graph interpretation from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of graph interpretation; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-107.L03`

### L04 — Quantitative claims

- **Outcome:** Evaluate and justify decisions about quantitative claims in the context of mathematics and science literacy.
- **Example brief:** Use a realistic fictional case involving quantitative claims; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to quantitative problem set.
- **Knowledge check:** Explain quantitative claims from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of quantitative claims; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-107.L04`
