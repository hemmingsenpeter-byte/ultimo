## Lesson blueprints

### L01 — Crisis roles

- **Outcome:** Explain crisis roles in the context of crisis leadership.
- **Example brief:** Use a realistic fictional case involving crisis roles; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to tabletop crisis exercise.
- **Knowledge check:** Explain crisis roles from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of crisis roles; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-108.L01`

### L02 — Safety and information

- **Outcome:** Compare and distinguish safety and information in the context of crisis leadership.
- **Example brief:** Use a realistic fictional case involving safety and information; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to tabletop crisis exercise.
- **Knowledge check:** Explain safety and information from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of safety and information; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-108.L02`

### L03 — Escalation

- **Outcome:** Apply escalation in the context of crisis leadership.
- **Example brief:** Use a realistic fictional case involving escalation; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to tabletop crisis exercise.
- **Knowledge check:** Explain escalation from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of escalation; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-108.L03`

### L04 — After-action review

- **Outcome:** Evaluate and justify decisions about after-action review in the context of crisis leadership.
- **Example brief:** Use a realistic fictional case involving after-action review; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to tabletop crisis exercise.
- **Knowledge check:** Explain after-action review from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of after-action review; correct application to a new case; clear rationale and limits.
- **Competency ID:** `LEA-108.L04`
