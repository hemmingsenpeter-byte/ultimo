# INT-106 / L04 — Intervention points

**Draft — independent review pending.** Outcome: Evaluate and justify decisions about intervention points in the context of systems thinking.

## Orientation and retrieval

Retrieve stocks, loops and delays. When a process repeatedly disappoints, what is the difference between changing its resources and changing its operating rules?

## Core teaching

A leverage point is a place where an intervention can change system behaviour. Possible interventions include adjusting parameters, changing capacity or delays, improving information, redesigning decision rules, or reconsidering the system's goal. A powerful intervention in one context may be weak or harmful in another. An intervention should be evaluated against an explicit objective and side constraints, not merely its ability to move a metric. For example, closing jobs more quickly may improve a backlog measure while increasing rework if quality is ignored. A local improvement can shift pressure elsewhere. Use stakeholder input and investigate the wider boundary before proposing structural changes. Test reversible interventions where possible and define monitoring and stopping criteria.

## Framework

Use goal–mechanism–options–test. Define desired outcome and guardrails; locate the loop or bottleneck; compare three interventions at different structural depths; predict side effects and delays; choose a bounded pilot and monitor both outcome and guardrails. This is an original decision worksheet inspired by systems thinking, not a universal hierarchy.

## Worked example

A fictional repair desk has a growing backlog. Hiring is a capacity intervention; showing technicians the oldest requests improves information; changing priority rules alters allocation. A pilot might test revised triage plus workload visibility while measuring waiting time, repeat visits and equitable access. If waiting falls but rework increases, the change fails a guardrail even if closure counts improve.

### Contrasting case

Doubling throughput by deleting unresolved tickets changes the reported metric but not the underlying service. A target is not identical to the outcome it represents.

## Guided practice

Compare three responses to delayed library returns: more copies, clearer reminders, and revised borrowing rules. Explain each mechanism, possible unintended consequences and one measure beyond the immediate return rate. Model: a reminder pilot is relatively reversible; assess return rates and whether users face access barriers before scaling.
