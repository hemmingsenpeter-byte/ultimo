# INT-106 — Systems thinking

Framework defined; lesson content: **draft**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours.

## Lesson blueprints

### L01 — Stocks and flows

- **Outcome:** Explain stocks and flows in the context of systems thinking.
- **Example brief:** Use a realistic fictional case involving stocks and flows; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to system diagram.
- **Knowledge check:** Explain stocks and flows from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of stocks and flows; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-106.L01`

### L02 — Feedback loops

- **Outcome:** Compare and distinguish feedback loops in the context of systems thinking.
- **Example brief:** Use a realistic fictional case involving feedback loops; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to system diagram.
- **Knowledge check:** Explain feedback loops from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of feedback loops; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-106.L02`

### L03 — Delays

- **Outcome:** Apply delays in the context of systems thinking.

### L04 — Intervention points

- **Outcome:** Evaluate and justify decisions about intervention points in the context of systems thinking.
