# FIN-102 — Debt and credit

Framework defined; lesson content: **planned**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [FIN-101 — Budget and balance sheet](../FIN-101/syllabus.md)

## Lesson blueprints

### L01 — Interest

- **Outcome:** Explain interest in the context of debt and credit.
- **Example brief:** Use a realistic fictional case involving interest; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to debt comparison spreadsheet.
- **Knowledge check:** Explain interest from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of interest; correct application to a new case; clear rationale and limits.
- **Competency ID:** `FIN-102.L01`

### L02 — Fees and repayment

- **Outcome:** Compare and distinguish fees and repayment in the context of debt and credit.
- **Example brief:** Use a realistic fictional case involving fees and repayment; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to debt comparison spreadsheet.
- **Knowledge check:** Explain fees and repayment from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of fees and repayment; correct application to a new case; clear rationale and limits.
- **Competency ID:** `FIN-102.L02`

### L03 — Borrowing trade-offs

- **Outcome:** Apply borrowing trade-offs in the context of debt and credit.
- **Example brief:** Use a realistic fictional case involving borrowing trade-offs; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to debt comparison spreadsheet.
- **Knowledge check:** Explain borrowing trade-offs from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of borrowing trade-offs; correct application to a new case; clear rationale and limits.
- **Competency ID:** `FIN-102.L03`

### L04 — Hardship options

- **Outcome:** Evaluate and justify decisions about hardship options in the context of debt and credit.
- **Example brief:** Use a realistic fictional case involving hardship options; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to debt comparison spreadsheet.
- **Knowledge check:** Explain hardship options from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of hardship options; correct application to a new case; clear rationale and limits.
- **Competency ID:** `FIN-102.L04`
