# EMO-106 — Boundaries and assertiveness

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [EMO-101 — Emotional identification](../EMO-101/syllabus.md)

## Lesson blueprints

### L01 — Boundaries versus control

- **Outcome:** Explain boundaries versus control in the context of boundaries and assertiveness.
- **Example brief:** Use a realistic fictional case involving boundaries versus control; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to boundary scripts.
- **Knowledge check:** Explain boundaries versus control from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of boundaries versus control; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-106.L01`

### L02 — Assertive requests

- **Outcome:** Compare and distinguish assertive requests in the context of boundaries and assertiveness.
- **Example brief:** Use a realistic fictional case involving assertive requests; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to boundary scripts.
- **Knowledge check:** Explain assertive requests from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of assertive requests; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-106.L02`

### L03 — Declining

- **Outcome:** Apply declining in the context of boundaries and assertiveness.
- **Example brief:** Use a realistic fictional case involving declining; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to boundary scripts.
- **Knowledge check:** Explain declining from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of declining; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-106.L03`

### L04 — Safety and follow-through

- **Outcome:** Evaluate and justify decisions about safety and follow-through in the context of boundaries and assertiveness.
- **Example brief:** Use a realistic fictional case involving safety and follow-through; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to boundary scripts.
- **Knowledge check:** Explain safety and follow-through from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of safety and follow-through; correct application to a new case; clear rationale and limits.
- **Competency ID:** `EMO-106.L04`
