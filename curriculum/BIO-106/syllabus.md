# BIO-106 — Medical literacy

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [INT-103 — Probability and statistics](../INT-103/syllabus.md)

## Lesson blueprints

### L01 — Symptoms and signs

- **Outcome:** Explain symptoms and signs in the context of medical literacy.
- **Example brief:** Use a realistic fictional case involving symptoms and signs; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to fictional consultation brief.
- **Knowledge check:** Explain symptoms and signs from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of symptoms and signs; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-106.L01`

### L02 — Screening

- **Outcome:** Compare and distinguish screening in the context of medical literacy.
- **Example brief:** Use a realistic fictional case involving screening; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to fictional consultation brief.
- **Knowledge check:** Explain screening from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of screening; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-106.L02`

### L03 — Reference intervals

- **Outcome:** Apply reference intervals in the context of medical literacy.
- **Example brief:** Use a realistic fictional case involving reference intervals; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to fictional consultation brief.
- **Knowledge check:** Explain reference intervals from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of reference intervals; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-106.L03`

### L04 — Shared decisions

- **Outcome:** Evaluate and justify decisions about shared decisions in the context of medical literacy.
- **Example brief:** Use a realistic fictional case involving shared decisions; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to fictional consultation brief.
- **Knowledge check:** Explain shared decisions from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of shared decisions; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BIO-106.L04`

## Assessment
**Artifact:** Fictional consultation brief.

All mapped criteria at level 2; no averaging away missing criteria. Level 3 requires independent novel application, delayed reassessment and appropriate review. Equivalent accessible written, oral, visual, simulated or supervised evidence; no personal disclosure required.

**Review:** clinical reviewer. Draft educational framework only. Use fictional cases; no personal diagnosis, prescription, hazardous practice, financial/legal instruction or unqualified certification. Obtain qualified/local review before publication.
