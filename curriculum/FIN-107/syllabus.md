# FIN-107 — Business valuation

## Lesson blueprints

### L01 — Financial statements

- **Outcome:** Explain financial statements in the context of business valuation.
- **Example brief:** Use a realistic fictional case involving financial statements; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to enterprise valuation memo.
- **Knowledge check:** Explain financial statements from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of financial statements; correct application to a new case; clear rationale and limits.
- **Competency ID:** `FIN-107.L01`

### L02 — Profit cash and value

- **Outcome:** Compare and distinguish profit cash and value in the context of business valuation.
- **Example brief:** Use a realistic fictional case involving profit cash and value; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to enterprise valuation memo.
- **Knowledge check:** Explain profit cash and value from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of profit cash and value; correct application to a new case; clear rationale and limits.
- **Competency ID:** `FIN-107.L02`

### L03 — Valuation methods

- **Outcome:** Apply valuation methods in the context of business valuation.
- **Example brief:** Use a realistic fictional case involving valuation methods; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to enterprise valuation memo.
- **Knowledge check:** Explain valuation methods from memory and apply it to a different example; state one limitation.

### L04 — Sensitivity

- **Outcome:** Evaluate and justify decisions about sensitivity in the context of business valuation.
- **Example brief:** Use a realistic fictional case involving sensitivity; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to enterprise valuation memo.
- **Knowledge check:** Explain sensitivity from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of sensitivity; correct application to a new case; clear rationale and limits.
- **Competency ID:** `FIN-107.L04`
