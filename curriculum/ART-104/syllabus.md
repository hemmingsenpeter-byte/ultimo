# ART-104 — Photography

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [ART-101 — Drawing and observation](../ART-101/syllabus.md)

## Lesson blueprints

### L01 — Light and exposure

- **Outcome:** Explain light and exposure in the context of photography.
- **Example brief:** Use a realistic fictional case involving light and exposure; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to photo portfolio.
- **Knowledge check:** Explain light and exposure from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of light and exposure; correct application to a new case; clear rationale and limits.
- **Competency ID:** `ART-104.L01`

### L02 — Framing

- **Outcome:** Compare and distinguish framing in the context of photography.
- **Example brief:** Use a realistic fictional case involving framing; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to photo portfolio.
- **Knowledge check:** Explain framing from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of framing; correct application to a new case; clear rationale and limits.
- **Competency ID:** `ART-104.L02`

### L03 — Editing ethics

- **Outcome:** Apply editing ethics in the context of photography.
- **Example brief:** Use a realistic fictional case involving editing ethics; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to photo portfolio.
- **Knowledge check:** Explain editing ethics from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of editing ethics; correct application to a new case; clear rationale and limits.
- **Competency ID:** `ART-104.L03`

### L04 — Sequencing

- **Outcome:** Evaluate and justify decisions about sequencing in the context of photography.
- **Example brief:** Use a realistic fictional case involving sequencing; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to photo portfolio.
- **Knowledge check:** Explain sequencing from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of sequencing; correct application to a new case; clear rationale and limits.
- **Competency ID:** `ART-104.L04`
