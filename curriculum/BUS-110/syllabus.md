## Lesson blueprints

### L01 — Organisation structures

- **Outcome:** Explain organisation structures in the context of organisational design.
- **Example brief:** Use a realistic fictional case involving organisation structures; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to organisation design proposal.
- **Knowledge check:** Explain organisation structures from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of organisation structures; correct application to a new case; clear rationale and limits.
- **Competency ID:** `BUS-110.L01`

### L02 — Decision rights

- **Outcome:** Compare and distinguish decision rights in the context of organisational design.
- **Example brief:** Use a realistic fictional case involving decision rights; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to organisation design proposal.
- **Knowledge check:** Explain decision rights from memory and apply it to a different example; state one limitation.

### L03 — Coordination

- **Outcome:** Apply coordination in the context of organisational design.

### L04 — Accountability

- **Outcome:** Evaluate and justify decisions about accountability in the context of organisational design.
