## Lesson blueprints

### L01 — Specificity

- **Outcome:** Explain specificity in the context of athletic programming.
- **Example brief:** Use a realistic fictional case involving specificity; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to fictional periodised plan.
- **Knowledge check:** Explain specificity from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of specificity; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHY-107.L01`

### L02 — Training phases
