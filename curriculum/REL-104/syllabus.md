# REL-104 — Shared values

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites

## Lesson blueprints

### L01 — Values versus preferences

- **Outcome:** Explain values versus preferences in the context of shared values.
- **Example brief:** Use a realistic fictional case involving values versus preferences; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to shared decision exercise.
- **Knowledge check:** Explain values versus preferences from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of values versus preferences; correct application to a new case; clear rationale and limits.
- **Competency ID:** `REL-104.L01`

### L02 — Joint priorities

- **Outcome:** Compare and distinguish joint priorities in the context of shared values.
- **Example brief:** Use a realistic fictional case involving joint priorities; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to shared decision exercise.
- **Knowledge check:** Explain joint priorities from memory and apply it to a different example; state one limitation.

### L03 — Mutually acceptable options

- **Outcome:** Apply mutually acceptable options in the context of shared values.

### L04 — Reviews

- **Outcome:** Evaluate and justify decisions about reviews in the context of shared values.
