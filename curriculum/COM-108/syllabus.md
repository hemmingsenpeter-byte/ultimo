# COM-108 — Debate

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [INT-102 — Logic and argument](../INT-102/syllabus.md)

## Lesson blueprints

### L01 — Claims and rebuttals

- **Outcome:** Explain claims and rebuttals in the context of debate.
- **Example brief:** Use a realistic fictional case involving claims and rebuttals; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to structured debate.
- **Knowledge check:** Explain claims and rebuttals from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of claims and rebuttals; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-108.L01`

### L02 — Evidence versus rhetoric

- **Outcome:** Compare and distinguish evidence versus rhetoric in the context of debate.
- **Example brief:** Use a realistic fictional case involving evidence versus rhetoric; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to structured debate.
- **Knowledge check:** Explain evidence versus rhetoric from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of evidence versus rhetoric; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-108.L02`

### L03 — Respectful cross-examination

- **Outcome:** Apply respectful cross-examination in the context of debate.
- **Example brief:** Use a realistic fictional case involving respectful cross-examination; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to structured debate.
- **Knowledge check:** Explain respectful cross-examination from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of respectful cross-examination; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-108.L03`

### L04 — Revision

- **Outcome:** Evaluate and justify decisions about revision in the context of debate.
- **Example brief:** Use a realistic fictional case involving revision; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to structured debate.
- **Knowledge check:** Explain revision from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of revision; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-108.L04`
