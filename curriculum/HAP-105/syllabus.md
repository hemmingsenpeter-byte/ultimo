Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours.

## Lesson blueprints

### L01 — Flow construct

- **Outcome:** Explain flow construct in the context of flow.
- **Example brief:** Use a realistic fictional case involving flow construct; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to absorbing activity plan.
- **Knowledge check:** Explain flow construct from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of flow construct; correct application to a new case; clear rationale and limits.
- **Competency ID:** `HAP-105.L01`

### L02 — Challenge and skill

- **Outcome:** Compare and distinguish challenge and skill in the context of flow.
- **Example brief:** Use a realistic fictional case involving challenge and skill; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to absorbing activity plan.
- **Knowledge check:** Explain challenge and skill from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of challenge and skill; correct application to a new case; clear rationale and limits.
- **Competency ID:** `HAP-105.L02`

### L03 — Activity design

- **Outcome:** Apply activity design in the context of flow.
- **Example brief:** Use a realistic fictional case involving activity design; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to absorbing activity plan.
- **Knowledge check:** Explain activity design from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of activity design; correct application to a new case; clear rationale and limits.
- **Competency ID:** `HAP-105.L03`

### L04 — Model limitations

- **Outcome:** Evaluate and justify decisions about model limitations in the context of flow.
- **Example brief:** Use a realistic fictional case involving model limitations; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to absorbing activity plan.
- **Knowledge check:** Explain model limitations from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of model limitations; correct application to a new case; clear rationale and limits.
- **Competency ID:** `HAP-105.L04`
