## Lesson blueprints

### L01 — Property cash flow

- **Outcome:** Explain property cash flow in the context of property.
- **Example brief:** Use a realistic fictional case involving property cash flow; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to property sensitivity model.
- **Knowledge check:** Explain property cash flow from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of property cash flow; correct application to a new case; clear rationale and limits.
- **Competency ID:** `FIN-106.L01`
