# INT-101 — Learning how to learn

Framework defined; lesson content: **draft**. Year 1; Level 2 guided practice; Level 3 extension; 4 indicative study hours. [Read the course](README.md).

## Prerequisites
None.

## Lesson blueprints and authored materials
### [L01 — Learning versus familiarity](L01.md)

- **Outcome:** Explain learning versus familiarity in the context of learning how to learn.
- **Example brief:** Use a realistic fictional case involving learning versus familiarity; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to seven-day learning cycle.
- **Knowledge check:** Explain learning versus familiarity from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of learning versus familiarity; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-101.L01`
