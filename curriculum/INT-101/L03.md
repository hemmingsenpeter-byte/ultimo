## Core teaching

Feedback describes the difference between intended and actual performance. Useful feedback specifies the error, offers a way to improve and is followed by a second attempt. Transfer is using learning outside the original exercise. Identical questions can reveal recall but not necessarily flexible application. Transfer is particularly difficult when the new situation shares an underlying structure but looks different. Self-explanation is a useful technique in some conditions; do not treat all forms of practice or feedback as equally effective.

## Framework

Target → attempt → compare → correct → novel attempt. Compare the process and the answer, not merely whether the learner feels confident.

This sequence is an instructional model, not a universal law. Check its limitations against the contrasting case.

## Worked example

After learning correlation and causation, a student correctly identifies confounding in a study about ice cream and swimming. They then examine a claim that employees who take training earn more. Prior experience could influence both training access and pay, so the causal claim needs more evidence.

### Contrasting case

Reusing the exact ice cream example may show recall of a solution, not transfer.

## Guided practice

Ask a peer or use an answer key to review an explanation. Identify one specific misconception, correct it and create a different scenario. Model: replace 'correlation proves cause' with a statement about alternative explanations.

Attempt the exercise before comparing to the model answer. Correct one specific gap.

## Independent transfer

Apply a concept to an unfamiliar professional or creative problem and explain which features transfer and which do not.
