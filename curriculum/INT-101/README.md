# INT-101 — Learning how to learn

Draft · Year 1 · Level 2 guided practice · 4 indicative study hours, excluding extended practice. Not accredited. [Syllabus](syllabus.md).

## Outcomes
- Explain learning versus familiarity in the context of learning how to learn.
- Compare and distinguish retrieval and spaced practice in the context of learning how to learn.
- Apply feedback and transfer in the context of learning how to learn.
- Evaluate and justify decisions about build your own learning system in the context of learning how to learn.
