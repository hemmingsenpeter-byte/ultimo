# INT-101 — Learning how to learn

Draft; four hours of study plus a seven-day practice cycle. No prerequisites. Target: Level 2 (guided practitioner). Independent Level 3 requires additional repeat evidence.

## Outcomes
- Distinguish familiarity, recall, understanding and transfer.
- Create a spaced retrieval schedule and use corrective feedback.
- Evaluate a learning attempt using delayed recall and a novel task.
- Design and carry out a manageable seven-day learning cycle.
