# CIV-108 — Media literacy

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [INT-104 — Scientific reasoning](../INT-104/syllabus.md)

## Lesson blueprints

### L01 — Reporting versus commentary

- **Outcome:** Explain reporting versus commentary in the context of media literacy.
- **Example brief:** Use a realistic fictional case involving reporting versus commentary; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to verification dossier.
- **Knowledge check:** Explain reporting versus commentary from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of reporting versus commentary; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-108.L01`

### L02 — Source verification

- **Outcome:** Compare and distinguish source verification in the context of media literacy.
- **Example brief:** Use a realistic fictional case involving source verification; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to verification dossier.
- **Knowledge check:** Explain source verification from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of source verification; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-108.L02`

### L03 — Framing and manipulation

- **Outcome:** Apply framing and manipulation in the context of media literacy.
- **Example brief:** Use a realistic fictional case involving framing and manipulation; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to verification dossier.
- **Knowledge check:** Explain framing and manipulation from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of framing and manipulation; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-108.L03`

### L04 — Fact-checking

- **Outcome:** Evaluate and justify decisions about fact-checking in the context of media literacy.
- **Example brief:** Use a realistic fictional case involving fact-checking; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to verification dossier.
- **Knowledge check:** Explain fact-checking from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of fact-checking; correct application to a new case; clear rationale and limits.
- **Competency ID:** `CIV-108.L04`

## Assessment
**Artifact:** Verification dossier.

All mapped criteria at level 2; no averaging away missing criteria. Level 3 requires independent novel application, delayed reassessment and appropriate review. Equivalent accessible written, oral, visual, simulated or supervised evidence; no personal disclosure required.

**Review:** Historian, economist, legal or policy specialist as appropriate.. Respect consent, privacy and applicable rules; source and subject review before publication.
