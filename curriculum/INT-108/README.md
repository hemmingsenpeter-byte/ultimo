# INT-108 — Forecasting and decisions

Draft · Year 3 · Level 2 guided practice · 6 indicative study hours. Not accredited. [Syllabus](syllabus.md).

- Apply expected value in the context of forecasting and decisions.
- Evaluate and justify decisions about calibration in the context of forecasting and decisions.
