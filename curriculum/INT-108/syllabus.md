# INT-108 — Forecasting and decisions

Framework defined; lesson content: **planned**. Year 3; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites

## Lesson blueprints

### L01 — Resolvable forecasts

- **Outcome:** Explain resolvable forecasts in the context of forecasting and decisions.
- **Example brief:** Use a realistic fictional case involving resolvable forecasts; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to forecast journal.
- **Knowledge check:** Explain resolvable forecasts from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of resolvable forecasts; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-108.L01`

### L02 — Reference classes

- **Outcome:** Compare and distinguish reference classes in the context of forecasting and decisions.
- **Example brief:** Use a realistic fictional case involving reference classes; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to forecast journal.
- **Knowledge check:** Explain reference classes from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of reference classes; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-108.L02`

### L03 — Expected value

- **Outcome:** Apply expected value in the context of forecasting and decisions.
- **Example brief:** Use a realistic fictional case involving expected value; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to forecast journal.
- **Knowledge check:** Explain expected value from memory and apply it to a different example; state one limitation.

### L04 — Calibration

- **Outcome:** Evaluate and justify decisions about calibration in the context of forecasting and decisions.
- **Example brief:** Use a realistic fictional case involving calibration; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to forecast journal.

- **Evidence:** Accurate explanation of calibration; correct application to a new case; clear rationale and limits.
- **Competency ID:** `INT-108.L04`
