# INT-108 / L03 — Expected value

**Draft — independent review pending.** Outcome: Apply expected value in the context of forecasting and decisions.

## Orientation and retrieval

Recall how to express probabilities as fractions or decimals. Imagine a choice whose result could be either favourable or unfavourable.

## Core teaching

Expected value is the probability-weighted average of the possible values of an outcome. For mutually exclusive and exhaustive outcomes with probabilities summing to one, multiply each value by its probability and add. It is not necessarily a possible outcome and does not guarantee what happens in a single case. Compare options on incremental consequences using the same units and time horizon. Expected monetary value is not the same as expected utility: people may value avoiding a catastrophic loss more than obtaining a larger average return. Constraints, downside exposure, affordability, ethics and uncertainty in probabilities matter. A sensitivity analysis tests how the preferred option changes when uncertain inputs vary. Do not treat arbitrary probabilities as precise facts.

## Framework

Create a payoff table with actions, possible outcomes, probabilities and net values. Check completeness and sum of probabilities; compute each weighted total; inspect worst credible outcome and constraints; calculate a break-even probability where appropriate; document a decision and its limitations.

## Worked example

A fictional event can use a cheap supplier with 80% chance of net benefit 100 points and 20% chance of loss 100 points. EV = 0.8×100 + 0.2×(−100) = 60. A reliable option guarantees 50 points. The first has higher expected value, but the second may be appropriate if a loss is unacceptable. For the risky option, 100p − 100(1−p) = 50 at p = 0.75. Above 75% its expected value exceeds 50.

### Contrasting case

A gamble with a positive average payoff can still be unacceptable if one loss breaches a hard safety or solvency constraint. The average cannot override such a constraint.
