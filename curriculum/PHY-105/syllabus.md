# PHY-105 — Swimming and coordination

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
None; prior learning may be demonstrated.

## Lesson blueprints

### L01 — Buoyancy

- **Outcome:** Explain buoyancy in the context of swimming and coordination.
- **Example brief:** Use a realistic fictional case involving buoyancy; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to dry-land water safety plan.
- **Knowledge check:** Explain buoyancy from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of buoyancy; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHY-105.L01`

### L02 — Stroke coordination

- **Outcome:** Compare and distinguish stroke coordination in the context of swimming and coordination.
- **Example brief:** Use a realistic fictional case involving stroke coordination; show reasoning, a contrasting case and limitations.

- **Knowledge check:** Explain stroke coordination from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of stroke coordination; correct application to a new case; clear rationale and limits.
- **Competency ID:** `PHY-105.L02`
