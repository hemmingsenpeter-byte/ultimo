# COM-102 — Writing

Framework defined; lesson content: **planned**. Year 1; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [INT-101 — Learning how to learn](../INT-101/syllabus.md)

## Lesson blueprints

### L01 — Audience and purpose

- **Outcome:** Explain audience and purpose in the context of writing.
- **Example brief:** Use a realistic fictional case involving audience and purpose; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to edited memo.
- **Knowledge check:** Explain audience and purpose from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of audience and purpose; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-102.L01`

### L02 — Claims and evidence

- **Outcome:** Compare and distinguish claims and evidence in the context of writing.
- **Example brief:** Use a realistic fictional case involving claims and evidence; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to edited memo.
- **Knowledge check:** Explain claims and evidence from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of claims and evidence; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-102.L02`

### L03 — Paragraph structure

- **Outcome:** Apply paragraph structure in the context of writing.
- **Example brief:** Use a realistic fictional case involving paragraph structure; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to edited memo.
- **Knowledge check:** Explain paragraph structure from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of paragraph structure; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-102.L03`

### L04 — Revision

- **Outcome:** Evaluate and justify decisions about revision in the context of writing.
- **Example brief:** Use a realistic fictional case involving revision; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to edited memo.
- **Knowledge check:** Explain revision from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of revision; correct application to a new case; clear rationale and limits.
- **Competency ID:** `COM-102.L04`

## Assessment
**Artifact:** Edited memo.

All mapped criteria at level 2; no averaging away missing criteria. Level 3 requires independent novel application, delayed reassessment and appropriate review. Equivalent accessible written, oral, visual, simulated or supervised evidence; no personal disclosure required.

**Review:** Communication instructor; language instructor as needed.. Respect consent, privacy and applicable rules; source and subject review before publication.
