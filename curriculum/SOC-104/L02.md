# SOC-104 / L02 — Voluntary graded practice

**Draft — independent academic and qualified subject review pending.** Outcome: Compare and distinguish voluntary graded practice in the context of social confidence.

## Orientation and retrieval

Retrieve the skill criteria from L01. A fictional learner wants to practise introducing a topic to a group. How can the task be divided into voluntary, low-stakes steps without deliberately increasing distress?

## Core teaching

Graded practice in this lesson means organising an ordinary learning task into manageable components and varying task demands after feedback. It is not clinical exposure therapy, and the curriculum does not prescribe treating anxiety through self-directed fear exercises. The goal is to practise observable skills in a safe, voluntary setting, with accessible alternatives and a right to stop.

Start with a narrow skill, such as giving accurate information, asking a relevant question or declining an optional request respectfully. A written script or simulated response may be sufficient for an initial attempt. A later attempt might include a consenting partner or an unfamiliar fictional question if useful and wanted. Difficulty can change through the complexity of the information or number of decision points rather than through humiliation, time pressure or distress. The appropriate level depends on demonstrated understanding, capacity and preference.

Practice should include feedback and transfer. Repeating an identical introduction may improve recall without demonstrating adaptability. Use equivalent new cases and check the relevant criteria. A learner can choose an oral, written or visual response; do not demand that they progress to a public performance. The process should not require interaction with unwilling strangers, disclosure or unsafe situations. If persistent distress interferes with functioning, professional support may be appropriate; this curriculum cannot provide clinical treatment or assess readiness for regulated duties.

## Framework

**Skill–format–attempt–feedback–variation**

Specify one observable skill. Choose an accessible, low-stakes fictional task and voluntary format. Attempt it and receive specific feedback. Correct one gap and repeat with a novel equivalent case. Vary task complexity only when useful and agreed. Include a stop option and a route for appropriate support.

Text progression: scripted fictional response → new written or spoken scenario → optional consented dialogue. These are formats, not compulsory stages or a therapeutic hierarchy.

## Worked example

A fictional learner wants to explain a community event to a newcomer. In the first round they draft a short written explanation including purpose, time and cost. Feedback identifies a missing access contact. In the second round they use a new fictional activity and include the access route. An optional third round uses a consenting peer who asks an ordinary clarification question. The learner can remain with written practice if that fits the objective. The result is assessed for accurate information and respectful choice, not whether the learner appeared relaxed.

### Contrasting case

A practice plan requires approaching strangers until rejection no longer feels uncomfortable, with penalties for stopping. This is not a suitable educational exercise. It disregards consent, risks distress and does not necessarily test the intended communication skill.

## Guided practice

**Design three ordinary practice variants.** Objective: explain an activity accurately and ask whether the recipient wants more information. Variant A: write a response using given facts. B: use a different activity and respond to one fictional question. C: optional consenting role-play or written dialogue. Specify criteria and a stopping rule.

**Worked solution.** A checks complete factual information. B checks application to a new task and acknowledges unknowns rather than guessing. C checks turn-taking and respecting the recipient's choice. Stop or change format if the exercise is no longer wanted or useful; obtain appropriate support if persistent distress requires it. No progression is compulsory.

Now identify which part of the task changed between B and C. If oral delivery is not the target, do not interpret a written alternative as inferior evidence. A suitable variation tests the relevant skill, not unrelated performance demands.

Attempt before checking the worked solution. Identify a specific reasoning or communication correction and repeat using an equivalent fictional case. Assess observable task quality, not personality, popularity or another person's compliance.

## Independent transfer
