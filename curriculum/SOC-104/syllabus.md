# SOC-104 — Social confidence

Framework defined; lesson content: **planned**. Year 2; Level 2 guided practice, Level 3 independent extension; 6 estimated study hours. 

## Prerequisites
- [SOC-101 — Conversation](../SOC-101/syllabus.md)

## Lesson blueprints

### L01 — Confidence versus skill

- **Outcome:** Explain confidence versus skill in the context of social confidence.
- **Example brief:** Use a realistic fictional case involving confidence versus skill; show reasoning, a contrasting case and limitations.
- **Practice:** Create an annotated explanation with a concrete example and a counterexample. Connect the result to low-stakes practice plan.
- **Knowledge check:** Explain confidence versus skill from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of confidence versus skill; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-104.L01`

### L02 — Voluntary graded practice

- **Outcome:** Compare and distinguish voluntary graded practice in the context of social confidence.
- **Example brief:** Use a realistic fictional case involving voluntary graded practice; show reasoning, a contrasting case and limitations.
- **Practice:** Compare two cases or approaches using explicit criteria; identify an important limitation. Connect the result to low-stakes practice plan.
- **Knowledge check:** Explain voluntary graded practice from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of voluntary graded practice; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-104.L02`

### L03 — Feedback

- **Outcome:** Apply feedback in the context of social confidence.
- **Example brief:** Use a realistic fictional case involving feedback; show reasoning, a contrasting case and limitations.
- **Practice:** Work through a new case or simulation; document assumptions and steps. Connect the result to low-stakes practice plan.
- **Knowledge check:** Explain feedback from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of feedback; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-104.L03`

### L04 — Support needs

- **Outcome:** Evaluate and justify decisions about support needs in the context of social confidence.
- **Example brief:** Use a realistic fictional case involving support needs; show reasoning, a contrasting case and limitations.
- **Practice:** Analyse an unfamiliar case; defend a choice, identify uncertainty and revise after feedback. Connect the result to low-stakes practice plan.
- **Knowledge check:** Explain support needs from memory and apply it to a different example; state one limitation.
- **Evidence:** Accurate explanation of support needs; correct application to a new case; clear rationale and limits.
- **Competency ID:** `SOC-104.L04`
