# Reusable framework library

The course syllabus blueprints identify where frameworks belong. Author original model entries alongside lessons rather than filling this folder with placeholder models.

Each framework record should contain a stable ID, title, linked competency IDs, purpose, origin, source references, evidence strength, assumptions, when to use/not use, steps, accessible diagram or text equivalent, worked case, counterexample, practice and revision history.

Initial backlog: retrieval and spacing (INT-101); argument mapping (INT-102); base rates (INT-103); causal loops (INT-106); decision journals (INT-105/108); habit cues (MEN-101); demands/resources (MEN-106); event-interpretation-feeling-action (EMO-101); boundaries (EMO-106); reflective listening (COM-103); interests versus positions (COM-106); cash-flow and balance-sheet models (FIN-101); unit economics (BUS-102); bottleneck mapping (BUS-106); strategic diagnosis (LEA-107); ethical frameworks (PHI-105); scenario planning (CIV-109).

These are proposed entries, not authored interactive models. Use evidence and limits rather than treating models as universal rules.
